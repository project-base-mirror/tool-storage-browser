# S3 Explorer v0.7.2

- 日期：2026-08-05
- 状态：正式发布
- 主题：托盘驻留与安装版安全升级

## 托盘驻留

- 设置中新增可选的托盘驻留开关，默认关闭，因此升级后仍保持原有的关闭窗口即退出行为。
- 开启后，关闭或最小化主窗口会隐藏到系统托盘，传输队列继续运行；双击托盘图标或使用菜单可恢复窗口。
- 文件菜单和托盘菜单的“退出”走同一安全关闭流程：暂停活动任务、保存队列与设置，再释放托盘资源并退出。
- 传输完成与失败通知按批次合并显示，避免批量任务产生大量系统通知；自动化测试模式不会创建或操作真实托盘图标。

## 安装版安全升级

- 更新清单升级为 Schema 3，新增与 Release tag 固定绑定的 `checksumsUrl`；客户端继续兼容 Schema 1/2。
- MSI 安装版可在后台下载与当前安装类型匹配的安装包，流式限制下载大小，并使用同一 Release 的 `SHA256SUMS.txt` 校验 SHA-256。
- 下载完成后仍需用户确认；独立维护程序再次校验安装包，等待主程序安全退出，再通过系统 `msiexec.exe /qn /norestart` 安装并重新启动应用。
- Windows UAC 保持可见；安装结果和 MSI 日志写入 `%LOCALAPPDATA%\S3Explorer\updates\`，失败时保留可诊断状态。
- 便携 ZIP 继续打开 Release 下载页面，由用户手动替换；本版本不提供无人值守自动安装。

## 兼容性与升级

- v0.7.1 及更早版本尚不包含维护程序，需要先手动安装一次 v0.7.2；此后 MSI 安装版即可使用应用内升级流程。
- 两种 MSI 都携带独立、裁剪后的单文件 `S3Explorer.Updater.exe`；两个便携 ZIP 仍只包含 GUI 与 CLI 两个入口。
- Contract API 保持 1、Manifest Schema 保持 2、Contracts ABI 保持 `1.0.0.0`，Unity/CLI 发布接口没有破坏性变化。
- 当前发布链未配置受信代码签名，UAC 与 SmartScreen 行为和前一版本一致；本版本未新增或修改项目法律与安全基础文件。

## 验证

- 默认完整测试：445 项通过，5 项外部环境集成测试按设计跳过；Release 构建 0 警告、0 错误。
- 重点覆盖率：持久化 0.92、传输队列 0.63、同步计划 0.96、CDN 队列 0.72。
- 显式更新集成测试从公开 v0.7.1 Release 下载 framework-dependent MSI 与 `SHA256SUMS.txt`，完成真实 SHA-256 校验。
- GUI Smoke 与损坏配置恢复 Smoke 均为 17/17；损坏配置用例保留 6 份诊断证据。
- 双便携 ZIP、Unity Contracts SDK 与双 MSI 已干净重建并通过结构门禁；两种 MSI 各包含一个维护程序，便携 ZIP 不包含维护程序。
- 独立维护程序验证了裁剪发布可运行、非法参数返回码以及校验失败时不会启动安装器；直接与传递 NuGet 依赖未发现已知漏洞。
