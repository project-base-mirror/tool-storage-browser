# S3 Explorer v0.6.9

- 日期：2026-07-30
- 状态：实现完成，待正式发布
- 主题：本地 MinIO 门禁与配置持久化加固

## 真实对象存储回归

- 新增 `scripts/Test-LocalMinio.ps1`，默认启动名称唯一、镜像版本固定的隔离 MinIO 容器，并在结束后只清理该容器。
- 集成测试覆盖连接、Bucket 列表、Unicode 对象上传下载、复制移动、Multipart、版本状态、Policy、Tags、ACL 和安全清空。
- 可显式传入 Endpoint 与凭据复用已有 MinIO；没有测试环境时普通测试将集成用例标为 `Skipped`，本地 MinIO 门禁本身则失败，避免“没有执行却显示通过”。
- Amazon S3 继续使用 SDK 默认校验和策略；S3-compatible 服务只在需要时启用请求和响应校验和，提高 MinIO 等实现的兼容性。
- Provider 能力矩阵明确 MinIO Community 的 Bucket CORS 与 KMS 边界，不再用服务端不支持的操作制造假失败。
- 没有新增 PR 或 `main` 推送触发的慢速测试。开发阶段显式运行本地 MinIO；正式 tag 工作流仍负责发布树的完整复验。

## 持久化与事务一致性

- 连接、设置、同步任务、传输任务、CDN 配置、CDN 凭据和 CDN 作业统一使用耐久 JSON 存储。
- 写入先落到同目录临时文件并刷新到磁盘，验证成功后再替换主文件；保留最后有效备份，并清理遗留临时文件。
- 同一路径的并发读写串行化；取消只允许发生在提交前，防止主文件处于一半新一半旧的状态。
- 主文件损坏时先保留带时间戳的 `.corrupt-*` 证据，再从有效 `.bak` 恢复；允许为空的队列和设置才会在没有备份时显式回到默认值。
- 配置值在读取时归一化到 UI 与运行时支持的范围，损坏或越界设置不会让主窗口启动崩溃。
- S3 连接、CDN 凭据和 CDN 配置通过 DPAPI 加密事务日志一起提交；保存过程被中断时，下次启动恢复到一个完整快照，不暴露长期密钥。
- 新建、编辑、复制、删除、连接包导入和文件夹同步保存均采用“磁盘成功后再替换内存”语义，失败不会显示成已经保存。

## 启动、诊断与退出

- 启动按设置、连接、CDN 两类数据和任务队列分阶段加载；单个存储损坏时保留其证据和有效的其他分区，而不是让整个应用退出。
- 有恢复事件时显示一次汇总；自动化运行抑制交互弹窗，仍通过日志和恢复信息保留证据。
- 异步连接与同步命令统一捕获保存失败并显示应用内错误详情。
- 错误详情和日志在显示、复制与落盘前统一脱敏 Access Key、Secret、Token、密码和带凭据 URL。
- 日志按天和大小轮换：活动文件上限 10 MiB、每天最多保留 5 个轮换文件、默认保留 30 天。
- 退出时等待队列和配置保存，60 秒仍未结束就取消退出并报告问题，不强制关闭造成数据丢失。

## 兼容性与边界

- 现有 JSON schema 和连接包格式不变；旧文件无需手动迁移，首次成功保存后自动获得备份。
- 本版本不改变 Unity Contracts DTO 或 ABI；`AssemblyVersion` 继续保持 `1.0.0.0`。
- MinIO Community 的 CORS 是服务级配置，不支持 S3 Bucket CORS API；SSE-KMS 测试需要服务端预先配置 KMS。
- AWS SSO、AssumeRole、Web Identity 和账户分组调整到 v0.6.10，不在稳定性版本内混入新身份功能。
