# S3 Explorer v0.7.6

- 日期：2026-08-09
- 状态：正式发布
- 主题：单实例托盘与发布一致性维护

## 单实例与托盘通知

- 桌面端在当前 Windows 会话内保持单实例；重复启动只向已有实例发送激活信号并退出，隐藏或最小化的主窗口会重新显示，不再创建额外进程和托盘图标。
- 单实例协调使用稳定的会话级命名对象；自动化测试可使用隔离实例键，不会唤醒或覆盖正式用户进程。
- 关闭或最小化到托盘不再主动弹出传统系统气泡。传输完成与失败仍按批次合并，但改用无焦点、自动关闭的应用通知窗，避免 Windows 11 将旧式气泡显示为含义不明的“私密”占位。
- 新增 `SingleInstanceSmoke`：连续启动三次，要求两个后续进程退出码为 0、首个 PID 不变，并验证隐藏的首个窗口被重新显示。

## 发布 Mirror 一致性

- `publish --delete-mode mirror` 的提交顺序调整为：上传资源 → SHA-256 回读 → ACL → 上传并回读新 Manifest → 删除远端孤儿 → CDN 后处理。
- Manifest 上传或校验失败时不会执行删除；删除失败时命令保持失败，但已经发布的新 Manifest 只引用本地仍存在的对象，远端最多残留孤儿，不再出现旧 Manifest 引用已删除对象的窗口。
- 默认 `--delete-mode none`、安全 Prefix、Dry Run、结构化结果和 Provider 删除兼容路径保持不变。

## 维护与文档

- 新增 `docs/README.md` 文档索引和 `docs/versions/next.md` Next / Unreleased 机制；正式 `vX.Y.Z.md` 作为不可回写的发布历史快照。
- MainForm 的导航历史状态、前进/后退边界与 forward 截断规则下沉到独立协调类；非事件导航方法由 `async void` 改为可等待的 `Task`。
- 远端发布验收默认使用 digest-first：所有 MSI、self-contained ZIP 与其他 5 MiB 以上资产使用 GitHub SHA-256 digest 对照 `SHA256SUMS.txt`，不再重复下载大资产。

## 兼容性与限制

- Contract API 保持 1、Manifest Schema 保持 2、Contracts ABI 保持 `1.0.0.0`；连接、设置、传输与 CDN 持久化格式不变。
- 安装版可从 v0.7.5 及更早的 Schema 3 更新版本升级；便携 ZIP 仍由用户手动替换。
- 当前发布链仍未配置受信代码签名；本版本未新增或修改项目法律与安全基础文件。
- Windows 托盘曾经残留的幽灵图标属于 Explorer 缓存，升级不会主动修改系统托盘历史；新版本通过单实例和正常释放避免继续创建重复活动图标。

## 验证

- 默认完整测试：492 项通过，5 项外部环境集成测试按设计跳过；加密归档篡改测试改为确定性修改合法密文并连续重复通过；Release `-warnaserror` 构建 0 警告、0 错误。
- 单实例单元测试覆盖首次获取、后续激活、释放后重获和非主实例监听门禁；自动化连续三次启动只保留首个进程，并成功恢复隐藏窗口。
- GUI Smoke 17/17 通过；托盘通知内容、窗口属性与屏幕工作区定位具有 WinForms 回归测试。
- 发布包、依赖漏洞、隔离 MinIO、重点覆盖率以及正式 Release/Pages 验收在发布门禁中继续复核。
