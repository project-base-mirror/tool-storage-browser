# S3 Explorer v0.2.3

- 日期：2026-07-24
- 状态：由 Git 历史回填；当时未创建 tag/Release

## 已交付

- 对象列表分页与连续加载，限制单页大小和内存缓存上限。
- 设置页增加分页数与缓存上限，达到上限后停止继续加载并提示。

- 导航请求使用 revision/cancellation 防止旧请求覆盖新位置。
