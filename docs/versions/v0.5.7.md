# S3 Explorer v0.5.7

- 日期：2026-07-28
- 状态：正式发布
- 主题：内置日志、可控 CDN 测试与 CDN 连接迁移

## 已交付

### 应用内日志查看器

- “查看日志”直接打开应用内窗口，不再依赖系统关联的外部文本编辑器。
- 日志窗口支持选择日志文件、刷新内容、自动滚动到末尾和复制文本。
- 日志读取使用共享访问方式；客户端仍在写入当前日志时也可安全查看。
- 空目录、文件消失、读取失败和窗口关闭均有明确状态，不阻塞主窗口。

### CDN 下载测试可控性

- 下载测试运行时提供明确的“取消测试”入口，关闭窗口也会取消正在进行的请求。
- 新增显式总超时，覆盖连接、响应 Header 和有限响应体读取，避免服务端无响应时窗口长期停留在“正在测试”。
- 运行状态和底部按钮改为稳定布局，长状态文字、DPI 和字体缩放不再挤压操作按钮。
- 用户取消与超时使用不同提示；取消不会显示为协议或网络故障。

### CDN 配置随连接包迁移

- `.s3connections` 升级为格式 3，可随单个连接或全部连接导出相关 CDN Profile 和 Bucket/前缀 Binding。
- 默认无凭据导出会保留非敏感 CDN 配置，同时移除 Token、Header secret 及其凭据引用。
- 用户显式选择“包含凭据”时，S3 与 CDN 秘密值共用现有迁移密码，以 AES-GCM 保护后写入连接包；不复制本机 DPAPI 密文。
- 导入预览默认不导入凭据，只有用户显式勾选并成功解锁后才恢复秘密值。
- 导入会重映射 Profile、Binding 和连接 ID，处理同名策略与重复 ID；保存失败时回滚 S3 配置、CDN 配置和独立 CDN 凭据。
- 继续兼容格式 1、2 的旧连接包；旧版客户端不会读取格式 3，目标端应先升级。

## 安全与数据边界

- 应用内日志查看器不改变日志内容和脱敏规则，不上传日志。
- CDN 测试只读取用户指定的有限样本；取消和超时会终止请求及响应流。
- 普通连接包不包含 S3 SecretKey、SessionToken、CDN Token 或自定义 Header secret。
- CDN 凭据导入后重新写入目标机器的独立 DPAPI 存储，不与 S3 凭据文件混用。

## 已知限制

- 日志窗口是只读查看器，不提供全文索引、跨文件搜索或日志清理。
- CDN 下载测试仍是有限 Range 探测，不是持续测速、并发压测或完整文件校验工具。
- CDN 格式 3 迁移通用 Profile、Binding 与通用 HTTP 凭据，不会把云厂商控制台会话或外部令牌缓存打包。
