# S3 Explorer v0.5.10

- 日期：2026-07-28
- 状态：待正式发布
- 主题：单文件便携包、MSI 与签名发布链

## 已交付

### 单文件便携包

- framework-dependent 与 self-contained 两个 ZIP 中，桌面端和 CLI 都分别发布为单文件 EXE。
- 托管程序集和本机运行库不再作为 DLL 暴露在包目录；trimming 继续关闭，避免改变 AWS SDK、JSON 与 WinForms 反射行为。
- framework-dependent 包仍需要 .NET 10 Desktop Runtime；self-contained 包把运行时打入 EXE，并对单文件内容启用压缩。

### Windows 安装包

- 新增 `S3Explorer-v0.5.10-win-x64-setup.msi`，内置 self-contained 桌面端与 CLI。
- MSI 安装到 64 位 Program Files，创建开始菜单入口，并使用固定 UpgradeCode 支持后续小版本升级和卸载。
- 发布门禁直接读取 MSI 数据库，验证 ProductName、ProductVersion 和两个入口文件。

### Release 与代码签名

- GitHub Release、工作流留存、`SHA256SUMS.txt` 和 Pages 下载页都纳入 MSI。
- 发布脚本支持通过 Actions secrets 临时导入受信 PFX，对四个 EXE 与 MSI 执行 SHA-256 Authenticode 签名、RFC 3161 时间戳和签名验证。
- 可用 `CODE_SIGNING_REQUIRED=true` 强制正式发布必须签名；证书和密码不进入仓库、产物指标或 SignTool 命令行。

## 安全与兼容性

- MSI 默认按计算机安装，需要 Windows 提权确认；便携 ZIP 继续支持不安装运行。
- 未配置受信证书时，构建会明确生成未签名包；自签名不会被当作 SmartScreen 解决方案。
- 有效 OV/EV 或 Microsoft Artifact Signing 身份会显示可验证发布者并逐步积累信誉，但新发布者仍可能暂时看到 SmartScreen 提示。

## 验证

- Core 147 项、CDN Infrastructure 15 项、S3 Infrastructure 58 项、App 41 项，共 261 项 Release 测试通过；Release 构建 0 warning、0 error。
- 两种 ZIP 均只包含 `S3Explorer.exe` 与 `s3explorer-cli.exe`；framework-dependent 与 self-contained CLI 均可启动并显示帮助。
- MSI 构建 0 warning、0 error，数据库 ProductName/ProductVersion 与项目一致并包含 GUI/CLI；本地产物约 74.77 MiB。
- 发布结构与 Pages 更新清单检查通过；隔离 UI Smoke 16/16 通过并确认 v0.5.10 主窗体；应用与 WiX 安装项目的直接/传递 NuGet 依赖均未发现已知漏洞。

## 已知限制

- 仓库尚未配置真实受信代码签名证书，因此当前本地产物仍显示未签名；正式解决“发布者未知”需要配置外部发布者身份。
- MSI 当前提供标准安装/升级/卸载和开始菜单入口，尚未提供可选安装路径、桌面快捷方式或按用户安装模式。
