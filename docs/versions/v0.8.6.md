# S3 Explorer v0.8.6

发布准备日期：2026-11-03。正式发布状态以对应 GitHub tag、Release 和 Actions 成功记录为准。

## 账户与连接

- 新增独立 Cloudflare R2 账户类型，服务商模板随账户类型刷新；R2 继续使用 Cloudflare 提供方的 Access Key / Secret Key 凭据。
- 切换模板或账户类型时保留已填写的自定义 Endpoint；空地址或原模板默认地址可随模板更新。
- 保留明确选择的 AWS 服务类型与自定义代理 Endpoint，重开连接及当前连接包导入不再误改为通用 S3。旧服务类型修复仍用于旧格式迁移。

## 上传签名与 CLI

- 新增 Auto、Streaming、UnsignedPayload 上传签名方式。Auto 保持旧行为：R2 使用非流式兼容方式，其他服务保持 SDK 默认。
- 通用 S3 连接可显式选择 UnsignedPayload；仅允许 HTTPS Endpoint，保留 SigV4 请求认证和 Content-MD5 内容校验，不是取消认证，也不是 SigV2 切换。
- 单文件、目录批量、分片及零字节目录标记共用配置。签名前的内容校验预读不计入上传进度，完成后恢复流位置。
- CLI 的 profile add 支持 --upload-signing；新增 profile update，并在 list/show 输出签名模式。update 在统一配置锁内只改目标字段，保留并发新增连接与其他编辑。

## 凭据安全保存

- 修改凭据提供方或类型时先列出不兼容的对象存储、AWS External ID 和 CDN 控制面引用；确认后仅清这些引用及已解析秘密，不删除凭据，不清兼容引用。
- 取消确认不保存。持久化前重新核对引用与凭据，发现新的影响或并发修改则整体停止，要求重新检查。
- 统一配置在落盘前验证解析后的新凭据；非法 External ID 不会先写坏配置再报告失败。
- CLI 新增 credential update；清除受影响引用必须同时提供 --clear-incompatible-references --yes。

## 配置兼容

- 统一配置 Schema 2、连接包格式 6 和 DPAPI 保护方式不变。新增可选 uploadSigningMode 字段，省略时按 Auto 读取。
- 本机配置、复制、连接包导入导出和合并保留显式签名选择；模式不同不视为等价连接。
- 旧客户端不认识新增字段，回存或再次导出可能丢失显式模式。需要通用 S3 非流式上传时，应在支持此设置的版本间迁移。
