# S3 Explorer v0.8.8

发布准备日期：2026-11-05。正式发布状态以对应 GitHub tag、Release 和 Actions 成功记录为准。

## Windows 双向文件复制粘贴

- 在对象列表选择文件或目录按 Ctrl+C，状态栏显示可粘贴后，即可在 Windows 资源管理器按 Ctrl+V；支持多文件、中文嵌套路径、零字节文件、空目录和重复粘贴。
- 本地文件/目录 Ctrl+C → 对象列表 Ctrl+V，复用上传队列与冲突处理。本地 Ctrl+X 也只执行复制上传，不删除源文件。
- 对象导出使用原生 FileGroupDescriptorW / FileContents / IStream。先冻结对象身份清单，消费者请求内容时再下载到私有磁盘缓存，完成长度、身份及可用校验和检查后提供文件，不把未完成缓存当成成功文件，也不把大文件整体装入内存。
- 同连接内复制/剪切继续走原有服务端流程。新增取消文件剪贴板/下载，处理取消、退出、剪贴板被替换及异步完成竞态，不清除其他程序后来复制的内容。
- 修复超过 2 GiB 限额下载的整数溢出。详细使用与限制见 [Windows 文件剪贴板](../Windows-File-Clipboard.md)。

## 合并自 v0.8.7 之后的安全修复

- 同步和 S3 路径往返保真，保护重命名、队列目标冲突和 Windows 大小写映射；原始 gzip 下载保留字节，目录删除包含 marker，上传跳过符号链接/junction。
- GUI/CLI 配置三方合并避免旧快照覆盖，修复共享凭据、无凭据连接、服务类型和高级设置往返、显式端口及损坏密文备份验证。
- 修复认证失败状态、自动连接恢复、分片阈值与 CLI 失败/取消清理；强制终止或服务端拒绝清理仍有明确限制。
- 恢复 MinIO 空对象条件复制、Supabase 允许覆盖时的单次复制，以及使用 Cloudflare 专用目标条件的 R2 单次复制。未知能力不会降级为无条件覆盖或删源。
- 符合条件的 AWS 固定版本可编辑 Metadata 后另存到新 Key；保留原对象，并明确展示冲突、响应丢失和属性快照边界。安全原地编辑仍不开放。
- 修复前导斜杠精确下载链接、重定向目标身份核对与区域重试路径；不向不可信目标转发认证信息。
- 安装升级进入 MSI 事务，保护失败回滚与中文自定义目录；便携包识别更准确。Pages 仅在公开 Release 资产及摘要验证通过后更新，避免提前推送不可用下载地址。
- 完整逐项记录见 [审计修复](../Audit-Fixes-2026-11-04.md)、[后续修复](../Audit-Followups-2026-11-04.md) 与 [安全工作流](../Safe-Workflows-2026-11-04.md)。这些文档中的“未发布”描述是其记录时状态，当前版本状态以 Release 为准。

## 兼容性与已知限制

- 不改变统一配置 Schema 2、连接包格式 6 或 Contracts ABI；无需迁移已有配置。旧版不具备新的安全保护，不建议带着进行中任务降级。
- 文件剪贴板需保持应用运行，已请求文件需要对应大小的本地缓存空间；首次读取等待该文件完整下载。它不进入可恢复队列，退出后需重新复制。消费者（含剪贴板管理器）请求内容也可触发下载。
- 文件清单最多 10,000 项，受 Windows 路径/文件名限制；无法保真导出的名称明确拒绝，不静默改名。清单为逐对象快照，不是整个 bucket 的原子快照。
- 尚未验收实体 Windows 10/11、实际超过 4 GiB Explorer 搬运、目标覆盖对话框及完整断网/磁盘不足/长时间取消矩阵；大尺寸 ABI 和部分错误路径自动测试不替代这些场景。
- 未使用真实 AWS、R2、托管 Supabase 或生产凭据；SDK 协议回归和 MinIO 集成不代表所有云服务实测。Metadata 原地修改、Supabase 自动移动/分片复制和未知兼容服务条件能力仍保持安全限制。
