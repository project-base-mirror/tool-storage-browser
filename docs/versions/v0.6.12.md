# S3 Explorer v0.6.12

- 日期：2026-07-31
- 状态：正式发布
- 主题：阿里 OSS 发布兼容与属性下载

## 阿里 OSS 发布兼容

- 普通上传与 Multipart 初始化只在明确设置 Storage Class 时发送对应请求头，空值不再形成阿里 OSS 拒绝的非法请求。
- 阿里 OSS 的批量对象删除固定走兼容的逐对象删除路径；其他 Provider 遇到 `MissingSomeRequiredArguments` 时也会安全回退。
- Unity OSSTool 经 `S3ExplorerCliBackend` 完成真实 Contracts 协商、阿里 OSS 增量发布、Manifest 生成、CDN 回读和远端清理，保持 API 1 与 Manifest Schema 1。

## 属性页下载

- 对象属性页改用自动宽度标签列，长英文属性名不再折行，最后一行标签和值保持同一行。
- 底部操作区增加“OSS 下载”和“CDN 下载”，并保留尺寸正常的关闭按钮。
- OSS 下载复用持久传输队列、断点与限速设置；CDN 下载使用当前对象最长前缀下的默认关联及其可选凭据。
- CDN 响应先写入同目录临时文件，完整成功后才替换目标；HTTP 错误或中断不会留下半成品。
- 当前对象没有匹配的 CDN 关联时，属性页明确禁用 CDN 下载。

## 兼容性与安全

- Unity Contracts API、Manifest Schema、profile schema 和连接包格式均未变化。
- CDN 凭据只进入请求 Header，不写入下载文件名、状态提示或日志。
- 本版本不包含 Android 构建；Android Bundle 可在安装本版本后继续使用正式安装路径验证发布。
