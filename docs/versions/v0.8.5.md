# S3 Explorer v0.8.5

发布日期：2026-11-03。范围：账户分组与排序体验、Cloudflare R2 上传兼容。

## 账户管理

- 账户树增加“新建分组”、上移和下移按钮，Accounts 根节点及空白处提供新建连接／分组菜单。
- 账户可拖到分组或未分组，也可插到另一账户之前／之后；分组支持拖拽排序。原有右键菜单继续可用。
- 排序时保留已加载 Bucket、选中和展开状态；串行保存分组与连接健康状态，避免异步连接结果恢复旧位置。
- 实际连接设置变更时使旧 Bucket 列表失效，忽略已过期的列桶请求。

## R2 上传修复

- 修复 `STREAMING-AWS4-HMAC-SHA256-PAYLOAD not implemented`：仅对 CloudflareR2 的 PutObject 与 UploadPart 禁用 Streaming SigV4、AWS chunked 请求体和 SDK 默认流式 checksum。
- CLI 单文件／目录批量、GUI 上传、multipart 与零字节目录标记使用同一兼容策略。保留 SigV4 请求认证，要求 HTTPS。
- 显式计算并发送 R2 支持的 Content-MD5，校验读取不计入上传进度；按文件／分片预读后恢复流位置，内存有界。CLI `--verify` 仍可回读验证大小和 SHA-256。
- AWS、MinIO 及其他服务的默认签名与校验行为不变。使用 R2 时连接类型需选择 CloudflareR2（CLI `--type r2`）。

## 兼容性与验证

- 统一配置 Schema 2、旧账户配置格式和凭据保护方式不变。旧 v1/v2/v3 账户经分组排序、保存和重新加载后保持凭据及连接设置。
- 云端离线验证：核心 284 项、S3 基础设施 170 项通过；10 项无配置真实集成测试明确跳过。新增 R2 协议测试 12 项、CLI 单文件／目录及 `--verify` 路径测试 2 项通过。Release 交叉编译零警告、零错误。
- SDK 协议测试使用假凭据和内存 HTTP handler，验证实际签名头、Content-MD5、请求体、分片边界与并发上传，不访问用户账户。
- Windows 默认完整测试（含账户树回归）、重点覆盖率及隔离 MinIO 集成由该提交的 Validate 工作流执行；正式 tag 工作流复验测试、打包、隔离 GUI Smoke、资产 digest、下载 CLI 版本与 Pages。以对应 Actions 成功记录为准。
- 本次没有真实 R2 账户或凭据，未声称完成真实 R2 上传验收。R2 校验预读增加一次本地磁盘读取；不新增其他未支持的 R2 API 能力。
- 云端本地 MinIO 启动受镜像撤回与依赖下载网络策略限制，真实存储验收使用仓库已有 CI 中固定官方源码构建的隔离 MinIO。
