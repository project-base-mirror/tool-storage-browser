# S3 Explorer v0.8.1

- 日期：2026-08-22
- 状态：正式发布
- 主题：凭据交互与安装快捷方式修复

## 凭据创建与兼容性提示

- 对象存储连接窗口新增“新建凭据”入口，可直接创建与当前服务商兼容的 Access Key 凭据，无需关闭窗口再进入凭据中心。
- 创建成功后统一 Credential Vault 立即刷新，连接窗口自动选中新凭据；凭据仍通过统一配置事务和 DPAPI CurrentUser 保护，不在连接 Profile 中复制秘密。
- 凭据下拉为空时明确区分 Vault 为空与已有凭据的 Provider / 类型不兼容；Amazon S3、Alibaba OSS 与其他 S3-compatible Provider 继续使用严格兼容类型筛选，不会放宽为错误复用密钥。

## Windows 安装快捷方式

- 开始菜单和桌面快捷方式改为直接指向安装目录中的 `S3Explorer.exe`，并由 Windows 使用 EXE 内嵌图标。
- 开始菜单快捷方式从 advertised shortcut 拆为独立的普通快捷方式组件，使用注册表 KeyPath 管理安装、升级和卸载生命周期。
- `ARPPRODUCTICON` 与 MSI Icon 表继续保留，仅用于 Windows“程序和功能”中的产品图标，不再被开始菜单或桌面快捷方式引用。
- 安装包门禁会检查两种 MSI 的 Shortcut、Component、Registry 与 Icon 表，阻止快捷方式重新绑定 MSI 图标缓存。

## 兼容性与升级说明

- 统一配置格式、连接包格式、Contract API 1、Manifest Schema 2 与 Contracts ABI `1.0.0.0` 均保持不变。
- 已经显示白纸图标的旧任务栏固定项仍需取消固定，并从新版本开始菜单项重新固定一次；重新固定后，后续升级不再依赖旧 ProductCode 的 Windows Installer 图标缓存。
- 安装目录、UpgradeCode、程序入口和卸载路径保持不变。

## 验证

- 默认完整测试 538 项通过，5 项外部环境集成测试按设计跳过；Release `-warnaserror` 构建为 0 警告、0 错误。
- self-contained 与 framework-dependent 两种 MSI 均重新生成并通过结构门禁；开始菜单和桌面快捷方式目标均为 `S3Explorer.exe`，`Icon_` 为空，ARP 产品图标仍存在。
- 发布包脚本、更新清单和 PowerShell 语法检查通过；凭据窗口新增 3 组布局、兼容筛选、即时刷新和编辑器预选回归测试。
- 发布资产未配置受信代码签名，不能据此描述为已经消除 SmartScreen 提示。

## 已知限制

- Windows 不会可靠重写已经固定到任务栏的旧快捷方式元数据，因此旧白纸图标需要用户手动取消固定并重新固定一次。
