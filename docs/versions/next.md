本文件只记录已经合入 `main`、但尚未进入正式版本 tag 的变化。它不是版本号，也不表示已经正式发布。最近正式版本仍是 `v0.8.1`；已发布历史见 [`README.md`](README.md)。

## 新功能

- 新增顶级“凭据”菜单和独立凭据中心；CDN 配置中心只保留 CDN 配置与 Bucket/前缀关联。
- 新增凭据权限矩阵，以凭据为行、权限为列汇总显示 `√ / × / ? / —`；可直接执行无副作用检查或当前凭据的写入探针，原检查记录保留为二级详情。
- 写入探针、文件夹同步、对象复制/移动和 CDN Bucket 关联统一使用可编辑 Bucket 选择器；选项合并连接配置、上次成功列举缓存和本次在线结果，连接失败时仍可手动输入。

## 维护

- Debug 构建与附加调试器启动使用独立实例锁、`%APPDATA%\S3Explorer.Debug` 数据目录和 `[Debug]` 窗口标记，可在正式安装版驻留托盘时直接从 Visual Studio 验证界面；运行期间的配置写入不会修改正式配置。
- Debug 启动会将正式版统一加密配置刷新为隔离快照，Debug 可直接看到正式版已有的连接、凭据和 CDN 配置；快照只通过配置存储重新加密保存，设置、队列、日志和历史不会复制，Debug 修改不会回写正式配置。
