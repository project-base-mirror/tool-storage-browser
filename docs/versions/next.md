# Next / Unreleased

本文件只记录已经合入 `main`、但尚未进入正式版本 tag 的变化。它不是版本号，也不表示已经正式发布。最近正式版本仍是 `v0.8.3`；已发布历史见 [`README.md`](README.md)。

## 新功能

- 大文件下载使用有界并行 Range 请求，复用分片并发设置；下载分段最小 32 MiB，达到传输阈值且至少两个分段时启用。分段完成位图支持暂停恢复，不把稀疏文件长度当作已完成进度。

## 修复

- 下载恢复截去未被检查点确认的尾部；严格验证 Range 响应、长度和对象身份，服务器忽略 Range 时安全退回串行。重建临时文件前先持久化旧进度失效。
- 复制固定源版本/ETag；分片复制保留元数据、内容头和受支持的标签。移动使用条件删除并保持版本桶的删除标记语义，删除结果不明确时不自动重做整个移动。
- 暂停/中断的分片上传取消时先清理远端 uploadId；清理失败保留可恢复状态。上传在创建远端 MPU 前完成规划，自动增大分片以满足 10,000 分片上限。
- 队列持续落盘失败会停止调度并报告非持久化状态，避免任务永久停留 Running；修复存储后显式恢复可继续。

## 维护

- 自动重试采用抖动退避，并从首次失败起受持久化的 15 分钟时间预算及次数上限约束（含下一次等待）；不强制中止健康的长传输，显式继续/重试可重置时间预算。

- 检查点按 1 秒或 64 MiB 合并保存，身份变化、进度回退及关键状态立即落盘；下载保持数据先于检查点持久化。
- 上传、下载和复制数据请求共享进程内 16 请求上限，避免文件并发与分片并发相乘；控制请求不计入该数据请求预算。
- 传输 UI 合并绘制、隐藏页签延迟刷新、批次增量汇总；对象列表复用既有行及选择。
- 增加隔离 MinIO CI 门禁（集成测试必须执行且全部通过）、故障注入、条件删除及大文件恢复校验。

## 兼容性 / 数据格式

- 保持现有队列、设置和连续下载检查点可读取；分段位图是新增可选字段。旧版本不能安全解释新分段检查点，不建议带有进行中下载时降级。

## 已知限制

- 固定版本 MinIO Community 实测忽略 DeleteObject If-Match（SDK 已序列化该头），因此 MinIO 自动移动在产生任何复制/删除副作用前明确拒绝；普通复制、下载及人工删除不受影响。恢复自动移动需先验证可靠的条件删除能力。
- 条件删除依赖服务端遵守 If-Match；未验证的 S3 兼容服务不能据此宣称移动源安全。ETag 相同的版本/元数据替换无法仅凭 If-Match 区分；不支持条件删除时不会退回无条件删除。
- 自动化兼容性门禁覆盖隔离 MinIO；其他供应商仅在显式配置测试端点时运行，不代表已实测所有云服务。Windows 原生 UI 行为由 Windows CI 验证。
- 并发与持久化成本优化不构成公网吞吐提升承诺；实际速度仍受磁盘、延迟、限速及服务端约束。

## 第二轮：同步扫描

- 递归列举对独立前缀使用有界并发（默认 4 个请求），同一前缀分页仍顺序读取；提前结束或失败会取消并等待在途请求，保留全局数量上限。
- 同步在读取本地文件内容、列举远端子前缀前应用排除规则。只有能证明覆盖整个子树的 `目录/**` 等规则才剪枝；`目录/*` 不会误跳过更深层的包含文件。排除表达式每次扫描/分析只编译一次。
- 被剪枝目录的后代不会逐个发现，因此排除项计数不代表所有被剪枝文件总数。任何已发现的对侧排除项仍不可生成删除动作。
- 读取哈希前后核对本地文件长度、修改时间和创建时间，发现变化则停止分析并要求重试。未引入仅按大小/时间戳复用的持久哈希缓存：同大小修改后恢复时间戳会使此类缓存错误宣称内容相同；开启哈希比较时仍重新读取文件。真正可靠的跨次哈希缓存延后，不把扫描结果宣称为文件系统事务快照。

## 第二轮：传输边界与使用体验

- 普通上传、下载及文件夹批次统一提供覆盖、跳过、自动重命名、询问。下载映射转义避免原有 `_xNNNN_`/保留名歧义，队列按 Windows 大小写和父子路径原子检查目标占用；旧检查点路径不改名。
- 下载临时文件使用独占创建预留，存在同名普通文件时分配独立临时路径，避免把先前下载的后缀名对象当作临时数据截断。非覆盖下载提交不覆盖执行期间出现的新目标。
- 非覆盖上传使用服务端条件写入，不因条件失败重试为无条件覆盖。AWS/MinIO 的 Put/Multipart Complete 及 R2 单次 Put 有专门路径；其他服务商或上传组合暂不声称原子非覆盖，明确提示用户。普通显式覆盖仍保留只写权限使用方式。
- 大对象服务端复制复用队列、共享请求预算和有界分片并发，暂停后对账已上传分片，恢复固定源身份；完成阶段保存并核对目标身份。MinIO 自动移动限制保留。复制/移动的旧重名预检查不是跨对象原子事务，不承诺与并发外部修改完全隔离。
- AWS/MinIO 下载显式请求 checksum 元数据；额外 KMS 权限/接口不支持时可退回普通元数据，不能因此标为已验证。应用验证 FULL_OBJECT SHA-256、SHA-1、CRC32；CRC32 使用锁定 SDK 的流式实现。COMPOSITE、CRC32C、CRC64NVME 与无值状态明确显示未完成应用级完整验证，不把 ETag 当普通 MD5。
- 校验结果保留在任务详情；校验失败不替换目标，先持久化失效检查点再移除失败临时数据，显式重试重新下载。
- “等待完成后退出”不再套用 60 秒清理超时，再次关闭可取消等待、继续使用程序；暂停/取消与清理步骤仍按原有有界关闭策略处理。

## 第二轮：有限内容预览与确认编辑

- 对象菜单新增内容预览：白名单文本/JSON 最多 2 MiB；CSV 只读表格最多 200 行、50 列，编辑仍使用完整原始文件。HTML/脚本只按纯文本显示，不在浏览器或脚本宿主中执行。
- 静态 PNG/JPEG/BMP 最多 8 MiB、1600 万像素，解码前检查文件头及尺寸；不支持 SVG、动画 GIF/APNG、Parquet 或可执行文件预览。
- 文本可显式交给 Windows 记事本编辑，固定编辑器路径且不使用文件关联/shell 执行下载内容。保存并关闭后仍需确认上传；小文件回传使用原 ETag 条件替换，远端变更或条件失败不退回无条件覆盖。
- 编辑仅开放 AWS、MinIO、R2 的有条件单次 Put 路径，需有效对象身份且无 Content-Encoding。HEAD 明确显示 KMS/客户密钥或 Object Lock/Legal Hold 时仅预览，拒绝此简化编辑流程；回传前再检查保护状态。AWS/MinIO 原对象 AES256 会通过写入请求显式保留，R2 AES256 对象暂仅预览，不依赖桶默认加密防止降级。保留模型支持的内容头、用户元数据及标签；这是对象替换写入，未知或接口未披露的独立 ACL/加密/锁配置不能保证原样，确认框明确提示服务端默认策略。
- 失败、冲突、取消或回传结果不明确时，仍有修改的本地编辑文件会保留并显示路径，请用户另存/核对；成功确认回传的相同内容及未修改临时文件清理。
- 编辑回传是一次明确确认的小文件请求，不自动进入批量持久队列或触发 CDN 自动化；需要这些流程时可使用普通上传。没有自动监视文件并上传，也不执行编辑后的内容。
- ETag 条件保护内容身份，不构成跨对象事务，也不能原子区分 ETag 相同的元数据替换；回传前另行检查可观察的版本、时间与元数据变化。
