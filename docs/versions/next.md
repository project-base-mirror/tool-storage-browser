# Next / Unreleased

本文件只记录已经合入 `main`、但尚未进入正式版本 tag 的变化。它不是版本号，也不表示已经正式发布。最近正式版本为 `v0.8.5`；已发布历史见 [`README.md`](README.md)。

## 新功能

- Cloudflare R2 成为独立账户类型，服务商模板按账户类型刷新。
- 连接新增上传签名模式：Auto 保留旧行为，Streaming 使用 SDK 默认流式签名，UnsignedPayload 提供 HTTPS 非流式兼容方式并保留显式 Content-MD5 内容校验；GUI、CLI、本机配置和连接包同步支持。
- CLI 新增 `profile update --upload-signing` 和 `credential update`，读取连接时同时显示签名模式。

## 修复

- 切换账户类型或服务商模板保留已填写的自定义 Endpoint；空地址或原模板默认地址可随模板更新。
- 凭据提供方/类型更改会列出不兼容引用，用户确认后仅清除受影响的对象存储、AWS External ID 与 CDN 控制面引用，不删除凭据或其他兼容引用；保存时重新核验并发修改。
- 统一配置在写盘前验证解析后的新凭据，非法 External ID 不会先落盘再报错。
- CLI 签名设置在配置锁内仅修改目标字段，保留并发新增连接及其他编辑。
- 当前配置与连接包保留明确选择的 AWS 服务类型及自定义代理 Endpoint，旧格式服务类型修复不再误改现代配置。

## 维护

## 兼容性 / 数据格式

- 老配置未指定上传签名模式时按 Auto 读取，R2 保持非流式方式，AWS/MinIO 等保持原 SDK 行为；不按 Endpoint 自动改写已有服务类型。
- 连接包格式仍为 6，新增可选签名模式字段；模式不同不会作为等价连接合并。旧客户端回存可能丢失此新增字段。

## 已知限制

- 使用隔离测试数据与 SDK 请求记录验证，未使用真实 R2 凭据完成远端测试。
