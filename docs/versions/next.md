# Next / Unreleased

本文件只记录已经合入 `main`、但尚未进入正式版本 tag 的变化。它不是版本号，也不表示已经正式发布。最近正式版本仍是 `v0.7.5`；已发布历史见 [`README.md`](README.md)。

## 修复

- `publish --delete-mode mirror` 调整发布一致性顺序：资源上传、SHA-256 回读和 ACL 全部成功后，先上传并回读校验新的 `publish-manifest.json`，再清理远端孤儿对象。Manifest 上传失败时不会执行 mirror 删除；清理失败时命令仍返回失败，但最多残留孤儿对象，不再出现旧 Manifest 引用已删除对象的窗口。关联提交：`efd29f2`。
- 桌面端限制为当前 Windows 会话内单实例；重复启动只唤醒已有窗口并退出，不再创建额外进程和托盘图标。驻留和传输完成通知不再使用传统系统气泡：关闭或最小化不主动弹窗，传输结果改为无焦点、自动关闭的应用通知，避免 Windows 11 显示含义不明的“私密”占位。
