# Next / Unreleased

本文件只记录已经合入 `main`、但尚未进入正式版本 tag 的变化。它不是版本号，也不表示已经正式发布。最近正式版本仍是 `v0.8.3`；已发布历史见 [`README.md`](README.md)。

## 新功能

- 大文件下载使用有界并行 Range 请求，复用分片并发设置；下载分段最小 32 MiB，达到传输阈值且至少两个分段时启用。分段完成位图支持暂停恢复，不把稀疏文件长度当作已完成进度。

## 修复

- 下载恢复截去未被检查点确认的尾部；严格验证 Range 响应、长度和对象身份，服务器忽略 Range 时安全退回串行。重建临时文件前先持久化旧进度失效。
- 复制固定源版本/ETag；分片复制保留元数据、内容头和受支持的标签。移动使用条件删除并保持版本桶的删除标记语义，删除结果不明确时不自动重做整个移动。
- 暂停/中断的分片上传取消时先清理远端 uploadId；清理失败保留可恢复状态。上传在创建远端 MPU 前完成规划，自动增大分片以满足 10,000 分片上限。
- 队列持续落盘失败会停止调度并报告非持久化状态，避免任务永久停留 Running；修复存储后显式恢复可继续。

## 维护

- 自动重试采用抖动退避，并从首次失败起受持久化的 15 分钟时间预算及次数上限约束（含下一次等待）；不强制中止健康的长传输，显式继续/重试可重置时间预算。

- 检查点按 1 秒或 64 MiB 合并保存，身份变化、进度回退及关键状态立即落盘；下载保持数据先于检查点持久化。
- 上传、下载和复制数据请求共享进程内 16 请求上限，避免文件并发与分片并发相乘；控制请求不计入该数据请求预算。
- 传输 UI 合并绘制、隐藏页签延迟刷新、批次增量汇总；对象列表复用既有行及选择。
- 增加隔离 MinIO CI 门禁（集成测试必须执行且全部通过）、故障注入、条件删除及大文件恢复校验。

## 兼容性 / 数据格式

- 保持现有队列、设置和连续下载检查点可读取；分段位图是新增可选字段。旧版本不能安全解释新分段检查点，不建议带有进行中下载时降级。

## 已知限制

- 固定版本 MinIO Community 实测忽略 DeleteObject If-Match（SDK 已序列化该头），因此 MinIO 自动移动在产生任何复制/删除副作用前明确拒绝；普通复制、下载及人工删除不受影响。恢复自动移动需先验证可靠的条件删除能力。
- 条件删除依赖服务端遵守 If-Match；未验证的 S3 兼容服务不能据此宣称移动源安全。ETag 相同的版本/元数据替换无法仅凭 If-Match 区分；不支持条件删除时不会退回无条件删除。
- 自动化兼容性门禁覆盖隔离 MinIO；其他供应商仅在显式配置测试端点时运行，不代表已实测所有云服务。Windows 原生 UI 行为由 Windows CI 验证。
- 并发与持久化成本优化不构成公网吞吐提升承诺；实际速度仍受磁盘、延迟、限速及服务端约束。
