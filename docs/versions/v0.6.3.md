# S3 Explorer v0.6.3

- 日期：2026-07-29
- 状态：正式发布
- 主题：传输启动修复与队列诊断

## 严重问题修复

- 修复 `PowerCreateRequest`、`PowerSetRequest` 和 `PowerClearRequest` 错误绑定到 `powrprof.dll` 的问题；这些 API 现在从 Windows `kernel32.dll` 调用。
- 防休眠只是一项传输辅助能力。系统不提供相关 API、入口点不可用、架构不兼容或创建电源请求失败时，现在会安全降级，不再让上传、下载、复制、移动或删除任务在启动阶段失败。
- 保留嵌套传输租约的计数与释放行为，最后一个传输结束后才清除系统电源请求。

## 传输队列诊断

- 底部任务区统一提供“全部”“进行中”“成功”“失败”视图；成功视图只包含真正完成的任务，取消任务保留在全部视图中。
- 新增内置“传输任务详细信息”窗口，显示任务、批次、来源、目标、进度、时间、重试次数和完整错误字段。
- 支持双击、Enter、工具栏或右键打开详情；支持右键或 `Ctrl+C` 复制完整详情，错误文本不再受列表列宽限制。
- 详情继续使用脱敏后的安全错误消息，不把连接密钥或令牌复制到剪贴板。

## 回归原因与测试补强

- v0.6.2 的传输队列测试使用了假执行器，GUI Smoke 只验证窗口和控件可用，没有走到真实 `S3TransferTaskExecutor` 的电源请求阶段，因此没有发现错误的 DLL 入口点绑定。
- 新增原生函数绑定断言、真实 Windows 电源请求嵌套租约测试，以及从 `S3TransferTaskExecutor` 进入实际 `WindowsSleepInhibitor.Acquire()` 的执行链回归测试。
- 新增任务状态分类、完整详情格式、敏感内容脱敏和高 DPI/大字体按钮布局测试；WinForms 测试改为串行运行，避免全局字体状态互相污染。

## 验证

- Core 153 项、S3 Infrastructure 58 项、CDN Infrastructure 15 项、CLI 6 项、App 49 项，共 281 项测试通过。
- Release 构建 0 警告、0 错误；GUI 自动化 Smoke 16/16 通过。
- 普通 ZIP、自包含 ZIP 与 MSI 的版本、单文件入口和 SHA-256 由发布门禁验证。

## 已知限制

- 防休眠能力不可用时传输会继续，但 Windows 仍可能按系统电源策略进入睡眠；该降级不会伪装为已经成功阻止睡眠。
- 公共发布包是否通过 SmartScreen 取决于正式代码签名配置与发布者信誉；未签名包不会被描述为已解决 SmartScreen。
