# S3 Explorer v0.5.2

- 日期：2026-07-27
- 状态：开发完成，待 `v0.5.2` tag 发布
- 主题：连接导入导出、复制与健康状态

## 已交付

### 可移植连接包

- 支持导出当前连接、账户树右键导出单个连接，以及一次导出全部连接。
- 默认生成无凭据 `.s3connections` 文件，完全省略 Access Key、Secret Key 和 Session Token。
- 可显式选择携带凭据；含凭据连接包要求迁移密码，可在另一台设备解锁后直接导入使用。
- 文件菜单提供统一导入入口；导入前显示连接名称、类型、Endpoint、凭据状态和重名状态。
- 预览支持逐项勾选、全选和全不选。连接包即使含有凭据，导入凭据选项仍默认关闭。
- 同名连接支持自动重命名、覆盖和跳过。覆盖会保留本地连接 ID，以免破坏现有同步任务引用。
- 文件格式带明确标识和版本，并限制为最多 1,000 个连接、16 MiB；未知版本、异常结构和不支持的加密参数直接拒绝。

### 连接管理

- 文件菜单和账户右键菜单新增“复制连接”；副本使用新 ID 和自动去重名称。
- 为连接持久化未检查、正常和失败三种健康状态。
- 连接与“网络诊断”测试会更新最近检查时间；成功时同时更新最近成功时间，失败不会抹掉上一次成功记录。
- 账户树以绿色、红色和橙色区分正常、失败和缺少已保存凭据，悬停提示与连接详情显示健康记录。
- 导入、复制或重新编辑的连接不会继承不可靠的旧设备健康状态。

## 凭据与安全

- 本地配置仍由 Windows DPAPI CurrentUser 保护 Secret Key 与 Session Token。
- 跨设备含凭据导出不复用只能在本机解密的 DPAPI 密文；它使用 PBKDF2-SHA256（210,000 次迭代）派生 256 位密钥，并以 AES-256-GCM 认证加密整个载荷。
- 错误密码、被篡改密文或认证标签不匹配都会停止导入。
- 迁移密码不会保存；日志不记录密码或任何连接凭据。
- 详细使用与安全说明见 [连接导入导出](../Connection-Import-Export.md)。

## 兼容性与升级

- `profiles.json` 文档版本提升到 2，新增的健康字段均为可选；已有版本 1 配置可直接加载。
- 无凭据导入允许先保存连接配置，但连接在补充凭据前不能访问远端服务。
- `.s3connections` 格式版本 1 是新的跨设备接口；后续不兼容变化必须提升格式版本。
- 健康记录属于当前设备，不进入连接包。

## 已知限制与后续决策

- AWS shared credentials/config、环境变量和实例/容器角色仍有必要，但必须统一为独立“凭据来源”，计划在 v0.5.3 实现，避免把长期密钥复制进多个连接。
- AWS SSO 与 AssumeRole 涉及短期令牌刷新、角色链和独立缓存，继续分阶段接入，不与长期密钥共用存储模型。
- 账户分组对大量连接有价值，但会改变树结构和导入/同步引用，安排在后续账户组织版本，不阻塞本版迁移能力。
