## 已交付

- 引入 S3 Compatibility Policy，集中处理 Provider 对批量删除、复制和错误码的差异。
- Multi-Object Delete 不支持时回退为逐对象删除。
- Multipart Copy 不可用时采用受控兼容路径。
- 改进 Bucket/对象不存在与无权限响应的区分，避免把访问被拒绝误报为空列表。
- 修复 AWS SDK Multipart Copy 调用对齐问题。

## 行为与兼容性
