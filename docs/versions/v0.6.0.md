# S3 Explorer v0.6.0

- 日期：2026-07-28
- 状态：正式发布
- 主题：Bucket CORS、版本控制、默认加密与 Tagging

## 已实现

### Bucket CORS

- Bucket 管理窗口新增 CORS 页面，提供表格和 JSON 两种编辑方式。
- 支持读取、校验、格式化、保存和删除配置；校验来源、HTTP 方法、Header、Max Age 与 100 条规则上限。
- 保存后回读并比较标准化结果，避免服务端未接受配置时仍显示成功。

### 版本控制与默认加密

- 显示 `未启用`、`已启用`、`已暂停` 三种版本状态；启用或暂停前解释对后续写入和删除的影响。
- 明确禁止把已经启用的 Bucket 恢复成“从未启用”，只允许暂停。
- 默认加密支持未配置、SSE-S3 与 SSE-KMS；SSE-KMS 必须填写 Key ID，并按 Provider 能力开放。

### Bucket Tags

- 支持 Key/Value 表格编辑、读取、保存和删除。
- 本地检查 50 条上限、Key/Value 长度、重复 Key 和 `aws:` 保留前缀。
- 提示成本分配标签还需在云厂商控制台激活。

## 安全与兼容性

- 每次写入前显示当前值与目标值的差异，并默认停留在取消选项。
- 配置读取先写入局部结果，只有完整成功后才覆盖当前编辑内容。
- Amazon S3 开放全部能力；MinIO 开放官方兼容的 CORS、Versioning、Encryption 与 Tagging。MinIO SSE-KMS 仍要求服务端先完成 KMS 和 Key 配置。
- 未经验证的 S3-compatible Provider 保持禁用并显示原因，不发送试探性管理请求。

## 验证

- Core 153 项、S3 Infrastructure 58 项、CDN Infrastructure 15 项、App 42 项，共 268 项测试通过。
- 解决方案 Debug 构建 0 warning、0 error；MinIO 集成矩阵增加 CORS、Tagging、Versioning 与 SSE-S3 回读测试，未配置矩阵时保持安全跳过。

## 已知限制

- v0.6.0 不提供生命周期、Object Lock 或对象级 Tag/Metadata 编辑，这些功能仍按路线图留在 v0.7。
- SSE-KMS 的 Key 是否存在、调用者是否有权限由服务端最终验证，客户端只执行非空和 Provider 能力检查。
