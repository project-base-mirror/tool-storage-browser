# S3 Explorer v0.6.6

- 日期：2026-07-29
- 状态：正式发布
- 主题：Windows 应用图标、64 位安装目录与双安装包

## Windows 应用图标

- 将多尺寸 S3 Explorer 图标写入 `S3Explorer.exe` 的 Win32 资源，不再只在 WinForms 窗口运行时动态设置图标。
- 开始菜单、桌面快捷方式和“程序和功能”显式使用同一个图标资源；固定到任务栏后可由 Windows 直接读取应用图标。
- 图标生成脚本与最终 `.ico` 一并保留，后续可以稳定复现全部尺寸。

## 安装向导修复

- x64 MSI 的默认路径改为 `C:\Program Files\S3 Explorer\`，不再被 `WixUI_Advanced` 的 32 位默认目录带到 `Program Files (x86)`。
- 移除未配置项目许可时由 WiX 带入的 Lorem ipsum 占位协议页，不伪造项目尚未采用的许可证。
- 使用项目自有安装目录页选择路径，并直接提供“创建桌面快捷方式”复选框；开始菜单入口保持默认安装。
- MSI 保持按计算机安装、自动详细日志和明确完成页。

## 两种多文件安装包

- 推荐安装包 `S3Explorer-v0.6.6-win-x64-setup.msi` 使用 self-contained 多文件发布，包含 .NET 10 运行时，无需预装框架。
- 新增 `S3Explorer-v0.6.6-win-x64-framework-dependent-setup.msi`，使用多文件 framework-dependent 发布，需要系统预装 .NET 10 Desktop Runtime。
- 两个 MSI 均不再把全部 DLL 打入两个入口 EXE；GUI、CLI、托管程序集、运行时配置和依赖以普通安装文件部署。
- 两个便携 ZIP 继续保持只有 `S3Explorer.exe` 与 `s3explorer-cli.exe` 的单文件形式，便于解压即用，不与安装器布局混用。

## 发布与验证

- 发布资产增加到七项：两个便携 ZIP、Unity Contracts SDK、两个 MSI、发布指标和 SHA-256 清单。
- MSI 门禁分别检查安装模式、文件数量、托管程序集、运行时边界、64 位目录、许可页缺失、快捷方式选项和图标资源。
- 轻量远端验收实际下载较小的依赖框架 MSI；大型 self-contained ZIP 与 MSI 继续使用 GitHub digest 对照校验，完整验收才下载全部大文件。

本地发布门禁结果：313 项自动化测试通过，Release 构建 0 警告、0 错误，GUI Smoke 16 项通过，未发现已知 NuGet 漏洞。发布包结构检查确认 self-contained MSI 为 39.13 MiB、framework-dependent MSI 为 1.30 MiB；安装向导实际打开验证了 `C:\Program Files\S3 Explorer\` 默认路径、桌面快捷方式复选框和无许可占位页，并在执行安装前取消，系统未被修改。

## 兼容性与已知限制

- framework-dependent MSI 不会安装 .NET 10 Desktop Runtime；未安装时，Windows/.NET 主机会提示下载相应桌面运行时。
- 本版本修复图标资源，但不会改变 SmartScreen 发布者信誉；未配置受信代码签名时仍可能显示“发布者未知”。
- 项目当前没有声明正式开源许可证，因此安装器不显示许可协议页；后续如项目所有者选择许可证，应提交真实许可文件再恢复协议页。
