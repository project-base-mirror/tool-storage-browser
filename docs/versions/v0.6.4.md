# S3 Explorer v0.6.4

- 日期：2026-07-29
- 状态：正式发布
- 主题：连接类型恢复与测试诊断

## 测试连接结果

- 连接测试结果从底部单行标签改为独立多行区域，不再被固定高度页脚裁切。
- 结果区域支持滚动、选择和复制；成功结果显示实际凭据来源、Bucket 数量和耗时。
- 失败结果同时显示完整服务消息、错误代码、HTTP 状态、Request ID 和耗时，不再用错误代码替换服务端消息。

## S3 兼容连接

- 新建“其他 S3 兼容存储”时 Region 默认显示 `auto`，无需用户为常规兼容服务手工填写。
- `auto` 不表示实际数据位于美国区域；它只让通用兼容模板在 SigV4 必须包含 Region 时使用 `us-east-1` 作为内部兼容签名值。
- 如果具体服务商要求固定签名 Region，仍可在同一输入框中显式填写。
- 在 Amazon S3、Google Cloud Storage 和各 S3 兼容模板之间切换时，分别保留 Endpoint、Region、HTTPS 和地址风格草稿，切回后不会被示例模板覆盖。

## 旧连接与导入兼容

- 修复旧连接可能以 `AmazonS3` 枚举默认值保存、但实际继续使用非 AWS Endpoint 的状态。
- 同时满足“已保存密钥、类型为 Amazon S3、Endpoint 明确不是 AWS 官方域名”的连接会在加载时恢复为“其他 S3 兼容存储”，Endpoint、Region 和凭据保持不变。
- 本地连接存储和连接包导入执行相同恢复规则；后续正常保存或导出时会写入修复后的类型。
- AWS 官方、区域、VPC Endpoint、中国区域域名，以及使用 shared profile、环境变量、容器角色、实例角色或默认链的 AWS 连接不会被重分类。

## Unity Contracts SDK

- 正式 Release 新增独立的 `S3Explorer.Contracts-v0.6.4.zip`，Unity 不再需要从源码目录自行寻找或编译 DLL。
- SDK ZIP 只包含 `netstandard2.1` 的 Contracts DLL、XML 文档和接入说明，不混入桌面端便携包。
- 发布门禁校验 ZIP 精确内容、非空文件和程序集版本；Pages 同步提供固定版本下载入口。

- 旧连接恢复只处理能够明确判定为非 AWS Endpoint 且使用已保存密钥的记录，不根据账户名称猜测服务商模板。
- 公共发布包是否通过 SmartScreen 取决于正式代码签名配置与发布者信誉；未签名包不会被描述为已解决 SmartScreen。
