# S3 Explorer v0.7.3

- 日期：2026-08-07
- 状态：正式发布
- 主题：依赖升级与代码结构维护

## 测试基础设施

- `Microsoft.NET.Test.Sdk` 从 17.14.1 升级到 18.8.1，`coverlet.collector` 从 6.0.4 升级到 10.0.1，相应 NuGet 锁文件已重新生成。
- 测试工具升级作为独立提交完成，未与 AWS SDK 迁移或对象存储功能混合。
- coverlet 10 的行统计口径有所变化；重点覆盖率阈值未降低，四组门禁均通过。

## AWS SDK for .NET v4

- `AWSSDK.S3` 升级到 4.0.102，`AWSSDK.SecurityToken`、`AWSSDK.SSO` 和 `AWSSDK.SSOOIDC` 升级到 4.0.100.7。
- 迁移显式处理响应可空值和默认为 `null` 的集合，请求集合也在使用前明确初始化；未启用 `AWSConfigs.InitializeCollections` 全局兼容开关。
- Bucket/Object ACL 切换到 v4 的分离 API；生命周期、Expires、Retention、版本与 Multipart 分页字段按 v4 可空语义适配。
- 默认 AWS 凭据链改用 `DefaultAWSCredentialsIdentityResolver`；生命周期响应缺少天数时会拒绝编辑，不会静默写入 0 天。
- 兼容 MinIO 在缺少 Bucket Policy 时由 SDK 返回 404 响应而非抛出异常的路径。

## 结构与界面修正

- `MainForm` 的上传、下载、删除、复制/移动、Metadata 与属性操作移入独立 partial，主文件从 3578 行降到 2910 行。
- `S3StorageService` 拆出 Bucket 配置与对象 Metadata/Tagging/Object Lock partial，主文件从 2228 行降到 1305 行。
- CDN 配置的支持对话框、编辑器和布局帮助类移入独立文件，`CdnConfigurationDialog.cs` 从 1774 行降到 979 行。
- 拆分只移动原有代码；四个移动块已逐字符比较一致，未改变公开接口或运行行为。
- 设置页确定/取消按钮在大字体下保持可读且不重叠；新配置默认开启托盘驻留与传输通知，已明确保存的用户选择保持不变。

## 兼容性与升级

- Contract API 保持 1、Manifest Schema 保持 2、Contracts ABI 保持 `1.0.0.0`，Unity/CLI 发布接口没有破坏性变化。
- AWS SDK v4 为内部大版本升级；现有连接配置和凭据存储格式不变。
- 安装版可从 v0.7.2 通过应用内更新升级到 v0.7.3；便携 ZIP 仍由用户手动替换。
- 当前发布链仍未配置受信代码签名；本版本未新增或修改项目法律与安全基础文件。
