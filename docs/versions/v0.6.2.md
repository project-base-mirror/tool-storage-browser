# S3 Explorer v0.6.2

- 日期：2026-07-29
- 状态：正式发布
- 主题：Unity/CI Manifest 发布接口

## 已实现

### Unity 兼容发布契约

- 新增 `S3Explorer.Contracts`，目标框架为 `netstandard2.1`，可供 Unity 2021.3 工程直接引用。
- 契约包含版本化发布 Manifest、文件变化计划、发布结果、完整性验证结果和 CDN 批处理结果。
- Unity 侧只需保存 Profile、Bucket、Prefix 与 CDN Profile 标识；AccessKey、SecretKey、SessionToken 和 CDN 凭据仍由 S3 Explorer 管理。

### Manifest 增量发布

- `publish` 扫描本地产物并计算 Size/SHA-256，与远端 `publish-manifest.json` 比较，只上传新增和变化文件。
- 每个对象上传后都会重新下载并验证 Size/SHA-256；全部文件成功后才最后上传并验证 Manifest，失败发布不会推进远端发布状态。
- 支持 `--dry-run` 预览、`--full` 强制全量上传和 `--delete-mode none`；第一阶段不会自动删除远端对象。
- `verify` 可按本地 Manifest 对远端文件进行完整性复核。

### 自动化与 CDN

- 新增 `upload`、`publish`、`verify`、`cdn test` 和 `cdn warmup` 自动化命令，并扩展 `objects list` 与 `connection test` 等脚本入口。
- 全局支持 `--output json`、`--non-interactive`、`--timeout`、`--cancel-file`、`--log-file` 和明确退出码。
- 发布成功后可选择计算 CDN URL，并对变化文件及 Manifest 执行 CDN 预热；CDN 测试与预热复用独立加密凭据存储。

## 安全与兼容性

- CLI 与桌面端共享现有 DPAPI 加密连接和 CDN 凭据；发布命令不接收或写入长期密钥。
- 日志和操作错误继续经过敏感信息脱敏；`--data-dir` 可隔离 Unity/CI 的测试配置。
- Manifest 文件路径拒绝绝对路径、`.`、`..`、重复路径、非法大小和非法 SHA-256。
- `publish-manifest.json` 的 Schema 版本固定为 1；不支持的 Schema 会明确失败，不会按未知格式继续发布。

## 已知限制

- 第一阶段只支持 `--delete-mode none`，本地已删除文件不会自动从远端清理。
- 完整性验证会回下载每个已上传对象；大型发布可获得强校验，但会增加时间和下行流量。
- CDN 预热按文件顺序执行，尚未加入并发度控制或 Provider 专用批量预热 API。
