# S3 Explorer v0.8.2

- 日期：2026-08-24
- 状态：正式发布
- 主题：凭据权限矩阵与多云 CDN 控制面

## 凭据与权限检查

- 新增顶级“凭据”菜单和独立凭据中心；CDN 配置中心只保留 CDN 配置与 Bucket/前缀关联。
- 新增凭据权限矩阵，以凭据为行、权限为列汇总显示 `√ / × / ? / —`；可立即执行无副作用检查或显式授权的写入探针，历史记录保留为二级详情。
- 对象属性和内容下载拆成独立权限；下载检查只选择不超过 64 KiB 的对象，并在 Range、响应长度和流读取三层限制数据量。
- 写入探针取消后仍使用独立短超时清理已经开始上传的唯一对象；清理失败会显示具体远端范围。

## Bucket 选择与调试体验

- 写入探针、文件夹同步、对象复制/移动和 CDN Bucket 关联统一使用可编辑 Bucket 选择器，合并连接默认值、成功列举缓存与本次在线结果；连接失败时仍可手动输入。
- Debug 构建使用独立实例锁、`%APPDATA%\S3Explorer.Debug` 数据目录和 `[Debug]` 标记，可与正式安装版同时运行。
- Debug 启动把正式版统一加密配置重新保存为隔离快照，可直接使用已有连接、凭据和 CDN 配置；Debug 修改不会回写正式配置。

## CDN 凭据与多云控制面

- CDN 内容认证和控制面凭据正式分离：Bearer Token/自定义 Header 只用于内容 URL，云厂商 Access Key/API Token 由凭据中心管理并关联控制面。
- 新增腾讯云 CDN 原生 Provider：支持精确域名查询、URL 刷新、原生预热及任务状态查询，刷新和预热分别按服务端限制分批。
- 新增 Cloudflare 原生 Provider：使用 API Token 与 Zone ID 查询精确 Zone 并按 URL 清理缓存；Cloudflare 没有原生预热接口时明确改用内容 URL GET。
- App、CLI、后台任务和权限矩阵共用统一 Provider 目录；Cloudflare API Token 与 Cloudflare R2 的 Access Key 类型保持严格隔离。
- 携带认证的 HTTP 内容请求不再跟随跨源重定向，避免 Bearer Token 或自定义 Header 泄露给其他主机。

## 兼容性与数据格式

- 统一配置继续使用 Schema 2；连接包升级到 v6，用于保存 Cloudflare Zone ID 等非秘密控制资源标识，并继续安全导入 v1-v5。
- 无加密连接包按 v1-v6 实际载荷拒绝凭据、秘密及凭据引用，不能用错误标记夹带明文秘密。
- Contract API 1、Manifest Schema 2 与 Contracts ABI `1.0.0.0` 保持不变。

## 已知限制

- Cloudflare 不提供原生预热 API，本版本使用配置后的内容 URL GET 完成明确标注的预热。
- 普通 CDN 权限检查不会执行刷新或预热等有副作用操作；它验证凭据和域名/Zone 查询能力，实际写操作仍在用户明确发起时执行。
- 当前自动化环境没有腾讯云 CDN 或 Cloudflare 真实控制面凭据；发布验证覆盖 SDK/HTTP 协议、签名输入和离线响应，真实账号权限仍以用户配置后的权限检查结果为准。
