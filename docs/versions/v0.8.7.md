# S3 Explorer v0.8.7

发布准备日期：2026-11-04。正式发布状态以对应 GitHub tag、Release 和 Actions 成功记录为准。

## 修复

- 修复 v0.8.6 上传到 Cloudflare R2 时可能出现的 `Header 'x-amz-tagging' with value '' not implemented` 错误。普通上传和分片创建在没有有效标签时将 SDK `TagSet` 保持为 null，省略空 `x-amz-tagging` 请求头。
- null、空标签列表及仅含空白编辑行的标签均按无标签处理；分片复制来源没有标签时也省略该请求头。
- 显式非空标签继续按原有 SDK 规则编码、发送，保留空标签值及中文、空格和特殊字符；内容类型、缓存策略、自定义元数据、请求认证和现有上传签名设置保持原有行为。
- GUI 与 CLI 使用同一存储实现，同步包含此修复。

## 兼容性与安全边界

- 不改变配置格式、连接包格式、凭据存储和 Contracts ABI；无需迁移已有配置。
- 本次只修复空标签请求头，不新增 R2 非空对象标签能力；显式配置标签时仍受服务商能力约束。
- 未读取或修改真实存储凭据、账户及用户对象数据。

## 验证与限制

- 新增实际 AWS SDK HTTP 请求回归矩阵，覆盖各 S3 服务类型、R2 上传签名方式、普通/分片上传、空标签与非空标签，并检查元数据、内容类型、缓存策略和请求认证。
- 增加无标签分片复制的 SDK 序列化检查；现有空文件、目录标记、并发上传与上传签名测试继续覆盖请求头。
- [功能提交 CI](https://github.com/project-base-mirror/tool-storage-browser/actions/runs/41760183051) 和发布提交验证包含 Windows 锁定依赖、零告警构建、完整测试、重点覆盖率及隔离 MinIO；正式 tag 工作流进一步验证安装包、隔离 GUI Smoke、CLI 版本、资产摘要与 Pages。
- 请求回归使用假凭据和内存 HTTP handler；未使用真实 R2 账户完成远端上传测试，不将协议回归或 MinIO 验证描述为真实 R2 验收。
