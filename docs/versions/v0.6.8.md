# S3 Explorer v0.6.8

- 日期：2026-07-29
- 状态：正式发布
- 主题：CDN 配置批量管理与证书状态持久化

## CDN 配置中心

- CDN 配置和 Bucket/前缀关联列表支持多选，可对选中项目执行批量删除和检测。
- CDN 配置与关联均支持复制；副本使用新的唯一标识，CDN 配置名称会自动生成不冲突的“副本”名称。
- 新建、编辑、复制或刷新列表后保持刚才选中的项目，不再默认跳回第一项。
- 操作按钮根据选择数量和后台检测状态启用；检测期间同一按钮可用于取消。

## HTTPS 证书状态

- HTTPS 证书检测成功后保存完整检测结果和检测时间，重新打开配置中心仍可查看状态。
- 保存的结果与检测时的基础 URL 绑定；修改 URL 后自动清除旧结果，防止显示失效证据。
- 旧版配置文件缺少证书结果字段时按“尚未检测”读取，不需要迁移。
- 多选检测按配置逐项执行，支持超时、取消与成功/失败汇总。

## Bucket / 前缀关联检测

- 检测会在关联前缀下递归查找第一个真实对象，按最长前缀映射规则生成最终 CDN URL，再发送只读 HEAD 请求。
- 列表显示 HTTP 状态和缓存命中 Header；详细提示包含源对象与最终 URL。
- 检测不会上传、删除或修改对象，也不会修改 Bucket Policy、ACL 或 CDN 配置。
- 关联检测结果仅用于当前窗口诊断；用户明确要求持久化的 HTTPS 证书结果会写入配置。

## 保存语义与安全边界

- 子编辑窗口的“确定”只更新配置中心内的草稿，不立即写入磁盘。
- 底部“保存全部更改”统一校验并写入新增、编辑、复制、删除及证书检测结果，保持配置与独立凭据的原子性。
- 有未保存更改时显示醒目状态；关闭或取消窗口会询问是否放弃。
- 删除 CDN 配置时会同时暂存删除引用它的关联，并在确认框中显示受影响数量。

## 兼容性

- CDN 配置 JSON 继续使用原有结构，新增证书结果为可选字段。
- 连接包的 CDN 配置等价判断不依赖检测时间，证书状态变化不会导致重复导入连接。
- 本版本不改变对象存储连接、CDN 凭据加密或 Unity Contracts ABI。
