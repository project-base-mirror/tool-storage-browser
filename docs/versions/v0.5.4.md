# S3 Explorer v0.5.4

- 日期：2026-07-28
- 状态：正式发布
- 主题：CDN 内容交付第一阶段

## 已交付

### CDN 模型与关联

- 新增独立 CDN Profile、凭据和 Bucket/前缀关联，不把 CDN 域名或秘密混入 S3 连接。
- 一个 Bucket 可按 Key 前缀关联多个 CDN；解析时只使用最长匹配前缀，并优先选择同范围的默认项。
- CDN URL 保留路径层级并逐段编码，可为当前文件复制 URL 或使用系统浏览器打开。
- 配置和凭据使用版本 1 JSON 文档分别保存；未知文档版本或空记录会拒绝加载。

### 下载、预热与刷新

- 下载测试发送真实 `GET + Range`，显示状态码、最终 URL、响应头耗时、总耗时、样本吞吐、Content Header 和常见缓存 Header。
- HTTP 预热支持 HEAD、有限 Range GET 和显式完整 GET；有限模式不会因服务端忽略 Range 而无限读取。
- 通用刷新支持用户配置 HTTP 端点、方法、Body、Content-Type、Bearer Token 或自定义 Header。
- 刷新前展示目标 CDN 和 URL 并要求确认；响应正文只读取最多 4096 字符摘要。
- 应用关闭会取消仍在执行的 CDN 预热或刷新；下载测试窗口关闭会取消自己的请求。

### 桌面工作流

- 主菜单新增“CDN / 分发”，集中提供配置、URL、下载测试、预热和刷新。
- Bucket 右键新增“CDN 关联...”，新增关联时预选当前连接和 Bucket。
- 对象右键新增 CDN 子菜单；仅当恰好选择一个文件且存在有效默认关联时启用对象动作。
- CDN 配置中心统一管理 Profile、独立凭据和关联；下载测试使用独立结果窗口。
- 12pt 字体和最小窗口尺寸下，配置、测试与关闭按钮保持完整可见。

## 安全与数据边界

- CDN Secret 使用 Windows DPAPI CurrentUser 和独立 entropy 写入 `cdn-credentials.json`，不复用 S3 SecretKey；`cdn-config.json` 只保存非敏感字段和凭据 ID。
- 基础 URL 不允许内嵌用户名密码、查询参数或片段；刷新端点不允许内嵌凭据或片段。
- 自定义 Header 名称必须满足 HTTP token 规则，秘密值不能包含换行符。
- 日志只记录动作、Profile、状态码、耗时和读取字节，不记录 Authorization、自定义鉴权 Header 或 Secret。
- 刷新属于外部 CDN 写操作，但不会改变 S3 对象状态。

## 兼容性与升级

- 新增 `cdn-config.json` 和 `cdn-credentials.json`，现有 `profiles.json`、连接包、同步任务和传输队列格式均未变化。
- 未配置 CDN 时所有现有 S3 浏览、传输和 CLI 行为保持不变；可直接覆盖 v0.5.3 升级。
- 自动化模式把 CDN 文件放入隔离数据目录，不读取真实用户配置。

## 验证

- Core 123 项、CDN Infrastructure 8 项、S3 Infrastructure 36 项、App 16 项，共 183 项测试通过。
- Loopback HTTP 回归验证默认 `HttpClientHandler` 实际发送 Range，并读取 206、Content-Range 和缓存 Header。
- Release 构建零警告、零错误；隔离数据目录 UI 冒烟 16/16 通过并生成截图。
- NuGet 漏洞审计覆盖 9 个项目，未发现已知漏洞包；xUnit 2.9.3 的 Legacy 提示属于既有测试栈。
- 发布脚本验证 framework-dependent 与 self-contained 两个 v0.5.4 ZIP 均包含桌面端、CLI 和 CDN Infrastructure 程序集。

## 已知限制

- 通用刷新只适用于不要求厂商签名的 HTTP API；CloudFront、Cloudflare、阿里云和腾讯云签名 Provider 尚未实现。
- 暂无 Prefix Purge、持久 CDN 作业队列、上传完成自动刷新/预热或 CDN CLI。
- 本地 HTTP 预热成功不能证明所有地域边缘节点已经缓存。
- 完整 GET 预热会读取完整对象，应只在用户确认流量和源站成本后选择。
