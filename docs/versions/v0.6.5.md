# S3 Explorer v0.6.5

- 日期：2026-07-29
- 状态：正式发布
- 主题：安装向导、CLI 传输控制与轻量远端验收

## Windows 安装体验

- MSI 从短暂的基础进度窗口升级为完整安装向导，安装结束会显示明确完成页，不再表现得像“闪退”。
- 高级安装可修改安装路径，并在功能列表中选择是否创建桌面快捷方式；开始菜单入口保持默认安装。
- 安装器启用 Windows Installer 自动详细日志。安装失败时可在 `%TEMP%` 中查找最新的 `MSI*.log`，无需抢截瞬时错误窗口。
- 发布门禁直接检查 MSI 的安装目录对话框、可选桌面快捷方式、自动日志属性、产品版本与两个单文件入口。

## CLI 直接启动与参数校验

- 在资源管理器中双击 `s3explorer-cli.exe` 时显示完整命令和参数帮助，并等待按键后退出。
- 从 PowerShell、Unity、CI 或重定向管道调用时不暂停，脚本执行行为和退出码保持不变。
- 未知选项、缺少值、重复的单值选项，以及不属于当前命令的已知选项都会返回参数错误，不再静默忽略拼写或配置错误。

## CLI 传输控制

- `--transfers` 控制文件级并发，`--multipart-concurrency` 控制单个大文件的分片并发；两者范围均为 1–32，默认值为 4。
- `--upload-limit` 与 `--download-limit` 以 KiB/s 设置命令级共享限速，多个并发文件不会各自获得一份限额。
- `--multipart-threshold` 与 `--part-size` 以 MiB 显式设置分片阈值和大小，并复用桌面端已经验证的传输执行器。
- `upload` 与 `object upload` 支持 `--verify`，上传后回读校验大小和 SHA-256；`publish` 继续强制逐文件验证并最后提交 Manifest。
- 目录上传、递归下载、同步执行、Manifest 发布和 Manifest 验证使用有界文件级并发；超时与取消仍传播到全部并发任务。

## 发布验收

- 新增 `scripts/Verify-RemoteRelease.ps1`，验证正式 Release 状态、精确资产集合、非空大小、SHA-256、普通 ZIP/SDK 内容、CLI/Contracts 版本和 Pages。
- 默认只下载普通 ZIP 与小型元数据；大型 self-contained ZIP 和 MSI 使用 GitHub 资产 digest 对照 `SHA256SUMS.txt`，digest 缺失或不一致会失败。
- 安装器、签名或打包链变化时使用 `-FullDownload`；正式签名验收同时使用 `-RequireSigning`。

## 兼容性与安全边界

- CLI 新参数均为可选项；未设置时采用桌面端相同的 4 路并发、64 MiB 分片阈值和 16 MiB 分片大小，限速保持关闭。
- `publish --delete-mode none` 的安全语义不变，本版本不增加远端删除。
- MSI 仍为按计算机安装并需要 Windows 提权；本版本没有配置受信代码签名时，仍不能描述为已解决 SmartScreen。

## 验证

- CLI 参数、双击暂停判定、传输默认值、单位换算和并发上限均有自动化测试。
- Release 构建、完整测试、GUI Smoke、发布包结构、MSI 数据库和依赖漏洞检查均纳入发布门禁。
- 正式发布后同时执行 Release/Pages 工作流验收和一次安装器变更所需的完整资产下载验收。

## 已知限制

- MSI 自动日志由 Windows Installer 写入当前用户 `%TEMP%`，文件名为系统生成的 `MSI*.log`；应用内日志窗口不读取安装阶段日志。
- 受信代码签名仍依赖仓库所有者配置正式证书和 Actions secrets；未签名包可能继续触发 SmartScreen。
