# S3 Explorer v0.8.10

发布准备日期：2026-11-07。正式发布状态以对应 GitHub tag、Release 和 Actions 成功记录为准。

## 传输界面与操作

- 修复传输面板高度恢复和任务显示，完善清除已完成、清除所有及任务移除行为。
- 对象右键菜单增加“下载...”，支持文件、文件夹和多选，沿用传输队列与冲突处理。
- 修复 Bucket 选择窗口刷新按钮的显示与布局。

## 跨连接复制

- 支持将对象或目录复制到其他连接和服务商，包括切换连接后粘贴以及“复制到...”选择目标连接。
- 源和目标使用各自凭据，经本机传输；保留目录层级、空对象和支持的 Metadata，支持分片、续传及目标冲突处理。
- 源对象保留。目标采用自己的存储级别、加密和 ACL 默认配置；标签仅在两端支持时保留。
- 不支持可靠原子条件写入的服务仍有存在性检查与写入之间的并发窗口。

## 更新器

- 修复更新器启动与等待原应用进程退出的处理，保留进程身份校验和安装更新的安全边界。
- 从受影响的旧版首次升级时，请手动下载并运行本版 MSI；本次修复随新更新器安装后生效。

## 兼容性

- 连接配置与 Contracts ABI 不变。
- 跨连接传输使用队列格式 v2。回退旧版前，请先完成并清除跨连接任务，再完全退出应用。

## 验证与已知限制

- 本轮 30 份功能源码及测试与此前测试构建的 SHA-256 清单逐字节一致；随后独立更新发布版本信息。更新器 10 项离线安全检查与更新清单一致性检查通过。正式构建由现有 GitHub Actions 流程产生。
- 发布工作流执行版本清单校验、锁定恢复、测试、覆盖率、打包、包结构、隔离 Windows GUI Smoke 和资产 digest 验收。成功状态以对应工作流记录为准。
- 大型 MSI 与 self-contained ZIP 使用 GitHub 提供的 SHA-256 digest 对照 SHA256SUMS.txt，不重复下载大资产。
- 没有使用用户电脑、用户存储凭据或生产 OSS 进行实机端到端验收。自动测试不等同于实体 Windows 10/11 验收。
