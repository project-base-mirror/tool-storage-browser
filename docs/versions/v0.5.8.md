# S3 Explorer v0.5.8

- 日期：2026-07-28
- 状态：正式发布
- 主题：CDN 运维、持久任务与上传完成自动化

## 已交付

### CDN 配置运维信息

- CDN Profile 支持最多 2000 字符的非敏感备注，并随连接包迁移。
- HTTPS 基础 URL 可执行只读证书检测，显示生效/到期时间、剩余天数、TLS 协议、域名匹配和证书链状态。
- 检测只进行 TLS 握手，不发送 HTTP 请求或 CDN/S3 凭据；支持 30 秒超时与手动取消。

### 持久 CDN 作业队列

- 手动预热和刷新改为创建持久作业，主窗口不再同步等待外部 CDN 请求。
- 作业支持幂等键、活动中同 URL 去重、指数退避和随机抖动、失败重试、取消、完成历史清理和重启恢复。
- 不同 CDN Profile 可以并行，同一 Profile 默认串行，避免单一配置同时发出过多请求。
- Provider 契约支持同步完成和“提交后按 Provider 任务 ID 轮询”两种执行方式，为原生 CloudFront 等 Provider 预留扩展点。
- CDN 任务中心显示任务状态、动作、重试次数、Provider 任务 ID、响应状态和脱敏错误。

### 上传完成自动化

- Bucket/前缀关联可显式选择新对象上传后 HTTP 预热，以及覆盖对象后刷新或刷新后预热；升级后默认全部关闭。
- 仅当策略需要时，上传执行器才在写入对象前探测目标是否存在，并把快照持久化到传输任务。
- 上传完成事件只通知协调器生成持久 CDN 作业；真正网络请求由后台 Worker 执行。
- 启动后补扫自动化启用后的已完成上传，幂等键保证重复扫描不会重复执行。
- 目标探测或 CDN 操作失败不会把已成功的 S3 上传改成失败。

### 高 DPI 布局收口

- CDN 下载测试底部状态与按钮区域不再因长文字或字体缩放向右越界。
- 连接导出、连接包解锁和导入预览使用响应式布局；“继续导出”“解锁并预览”“全选 / 全不选”“导入所选连接”等操作在 12pt 字体和最小窗口下保持完整可见。

## 兼容性与数据

- `cdn-config.json` 和 `transfers.json` 继续使用 schema 1；新增字段都有安全默认值，旧文件可直接加载。
- 新增 `%APPDATA%\S3Explorer\cdn-jobs.json` 保存非敏感任务状态，不保存 CDN Token、Header secret 或 S3 密钥。
- 老版本会忽略新增 JSON 字段，但不理解 CDN 作业历史；回退前建议退出任务中心并备份应用数据目录。

## 已知限制

- v0.5.8 仍只有通用 HTTP Provider；CloudFront、Cloudflare、阿里云和腾讯云原生签名 API 尚未接入。
- 暂无 Prefix Purge、跨任务 URL/目录聚合、厂商配额窗口或 CDN CLI。
- HTTPS 证书检查不查询 CRL/OCSP，也不负责签发、续期或部署证书。
