- 日期：2026-08-01

- 主题：生命周期与 Object Lock

## 生命周期规则

- Bucket 管理增加生命周期 JSON 编辑器，支持前缀和 Tag 过滤、当前与非当前版本存储类型转换、对象过期、非当前版本过期，以及未完成 Multipart 自动清理。
- Core 在请求前验证规则 ID、重复过滤条件、Tag、动作完整性、转换顺序和所有天数字段；不支持的 Provider 子能力不会发送试探性写请求。
- 保存后强制回读并做语义比对；服务端丢失字段或改变规则时不会报告成功。
- 对已存在但使用绝对日期、对象大小过滤、`NewerNoncurrentVersions` 或 `ExpiredObjectDeleteMarker` 的配置，当前编辑器只报告不支持并阻止覆盖，避免静默丢失字段。

## Object Lock

- Bucket 页提供 Object Lock 与默认 Retention 的只读探测，不提供不可逆的事后启用或默认规则修改。
- 单对象属性页读取当前版本的 Retention 与 Legal Hold，并显示 Bucket 默认保留策略。
- Retention 与 Legal Hold 分别要求独立授权勾选；每次写入还会显示完整对象 Key、Version ID 和目标状态并逐对象确认。
- Compliance Retention 在本地阻止缩短和降级；客户端始终关闭 Governance Bypass。
- 普通对象属性页不会自动发起锁状态请求，仅在用户切换到 Object Lock 页时探测。

## Provider 边界

- Amazon S3 开放完整生命周期、Bucket Object Lock 探测和对象级写操作。
- 隔离 MinIO 已真实验证对象过期、非当前版本规则、回读和删除；存储分层转换需要额外服务端层配置，当前客户端不开放。
- 当前锁定的 MinIO 镜像会丢失或拒绝 `AbortIncompleteMultipartUpload` 生命周期规则，因此该子能力在 MinIO 上本地禁用。
- 其他未验证的 S3-compatible Provider 保持生命周期和 Object Lock 写能力禁用。
