# S3 Explorer v0.8.3

- 日期：2026-09-30
- 状态：发布记录（资产以 GitHub Release 为准）
- 主题：剪贴板、上传响应性与可重现构建修复

## 剪贴板与桌面响应性

- 复制 CDN URL 在 Windows 剪贴板暂时被占用时进行有限次数的异步重试；重试让出 UI 消息循环，失败后显示可重试提示。
- 重复复制和窗口关闭会取消旧请求，避免过期请求覆盖当前状态。
- 上传高频进度以 150 毫秒间隔合并刷新，减少 UI 消息积压，并保留任务最终进度与状态。
- 传输执行放到后台线程，防止执行器的同步工作阻塞入队调用方。
- 新增剪贴板争用、重复操作、窗口关闭、上传期间交互、高频进度及阻塞执行器的回归测试。

## 构建与发布

- 精确固定 .NET SDK 10.0.400，禁止自动滚动到其他补丁版本，保持 SDK 隐式 Microsoft.NET.ILLink.Tasks 依赖与已提交锁文件一致。
- CI、Release 与安装生命周期工作流逐条检查 locked restore 的退出码；恢复失败立即停止，不再被后续成功命令掩盖。
- CI 的空白检查失败时同样立即停止。

## 兼容性与数据格式

- 统一配置 Schema 2、连接包 v6、Contract API 1、Manifest Schema 2 与 Contracts ABI `1.0.0.0` 保持不变。
- 不更改现有连接、凭据、任务或安装类型。
