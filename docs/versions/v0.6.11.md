# S3 Explorer v0.6.11

- 日期：2026-07-31
- 状态：正式发布
- 主题：账户组织与高级 AWS 身份

## 账户分组

- `profiles.json` 升级到 schema 4，连接分组成为独立配置实体，不混入应用布局设置。
- 主连接树支持新建、重命名、删除、上下移动分组，以及分组折叠状态和组内连接排序。
- 删除分组只把其中连接移到未分组，不删除连接、远端 Bucket 或对象。
- 连接导入预览可选择目标分组；完全等价的本机连接继续复用原记录和原位置。
- CLI 新增 `profile groups`、`group-add`、`group-delete` 和 `move --group`。

## AWS SSO

- IAM Identity Center 使用明确的 SSO Profile，读取 AWS config 和 SDK token cache。
- 普通浏览、同步、传输和自动化不会主动打开登录页；仅用户发起“测试连接”时允许 SDK 打开验证 URL。
- SSO account/role 和需要用户登录的状态可诊断，浏览器 token、user code 和刷新 token 不进入连接配置、连接包或日志。

## AssumeRole 与 Web Identity

- AssumeRole 支持源 Profile、目标 Role ARN、角色会话名称、可选 Source Identity、External ID 和 900–43200 秒会话时长。
- External ID 在日常配置中使用 Windows DPAPI CurrentUser 保护；诊断只显示“已配置/未配置”。
- Web Identity 只保存 token 文件绝对路径，由 AWS SDK 按需读取；应用不读取、缓存或导出文件内容。
- 角色会话按非敏感配置指纹缓存并由 SDK 刷新；连接测试在 SDK 已生成会话后显示到期时间。
- AWS SDK 3.7 服务包补齐 Security Token、SSO 与 SSO OIDC 实现，并保持锁文件可重复还原。

## 连接包与日志安全

- 连接包格式 3 增加高级身份的向后兼容可选字段，不导出账户分组。
- 默认无凭据包保留 SSO/角色非敏感配置，但省略 External ID。
- 显式选择凭据并设置迁移密码后，External ID 才随 S3/CDN 凭据进入整体 AES-GCM 加密载荷。
- SSO token、短期角色会话和 Web Identity token 内容在任何连接包模式下都不会导出。
- 错误和 CLI 日志新增 access/refresh/ID token、Web Identity token、External ID、client secret、device code 与 user code 脱敏。

## 兼容性

- 旧 schema 1–3 的 `profiles.json` 自动迁移为无分组 schema 4，原连接内容不变。
- 连接包格式仍为 3，导入器继续兼容格式 1 和 2。
- Unity Contracts ABI、Manifest schema 与自动化隔离数据目录不变。
- S3-compatible 连接仍锁定已保存密钥，不读取本机 AWS Profile、SSO 或角色链。
