# S3 Explorer v0.5.0

- 日期：2026-07-27
- 状态：由 Git 历史回填；未创建 tag/GitHub Release
- 主题：可用性、文件夹同步和命令行 API

## 已交付

### 界面与账户

- 统一菜单、工具栏、账户树和常用命令的矢量图标语言。
- 账户入口收敛为 Amazon S3、S3 兼容存储和 Google Cloud Storage；常见兼容服务由模板选择。
- Region 默认 Auto；无需用户配置 Region 的类型隐藏该字段，高级设置直接显示。
- 指定 Bucket/外部 Bucket 支持无 ListBuckets 权限账户，账户树使用不同颜色图标区分。
- Folder Sync 使用左侧任务列表切换；连接变化时 Bucket/path 跟随账户刷新，没有可用 Bucket 时显示明确空状态。

### 对象、同步与自动化

- 修复递归对象遍历，继续进入 CommonPrefixes，并增加分页令牌、前缀边界与数量上限保护。
- 持久化文件夹同步任务：上传/下载单向镜像、分析新增/更改/删除、Glob 排除、可选哈希和删除传播确认。
- 同步操作复用持久传输队列，本地/远端删除也以可审计任务执行。
- 独立 `s3explorer-cli` 提供 profile、connection、bucket、object、sync 命令，支持 JSON、明确退出码和隔离数据目录。
- Bucket 右键菜单补充上传、下载全部、同步、ACL、Policy、Public Access Block/Object Ownership、安全清空和属性入口。

### 构建与发布

- 发布包同时包含 GUI 与 CLI。
- 生成 framework-dependent/self-contained ZIP 和 `release-metrics.json`。
- 修复 Windows PowerShell 加载 ZipFile 类型的兼容问题。

## 行为与兼容性

- profiles.json 与旧版本兼容；Provider Catalog 会根据类型补齐安全默认值。
- sync-jobs.json 首次创建，默认删除传播关闭。
- CLI 与 GUI 共享 DPAPI CurrentUser 凭据，换 Windows 用户后不能直接解密。

## 验证

- 当前回归基线：Core 114、Infrastructure 28、App 4，共 146 项测试通过。
- CLI 离线 smoke、UI automation smoke 与发布包结构检查通过。
- 真实 Provider 测试仍保持环境变量显式 opt-in。

## 已知限制

- 同步是单向镜像，不是双向冲突合并；Multipart ETag 不能作为普通 MD5。
- CORS、生命周期、对象版本、Object Lock、自动更新和托盘驻留尚未实现。
- GitHub Pages/Release 与客户端更新检查计划在 v0.5.1 完成。
