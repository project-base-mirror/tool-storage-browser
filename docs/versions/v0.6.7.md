# S3 Explorer v0.6.7

- 日期：2026-07-29
- 状态：正式发布
- 主题：同步结果控制、Unity 契约兼容与 CDN 公开交付验证

## 文件夹同步第二阶段

- 分析结果支持逐项勾选，可按全部、已选择、新增、已更改、已删除和跳过筛选。
- 支持按路径、扩展名、差异类型、操作、本地/远端大小和原因排序；筛选与排序不会丢失勾选状态。
- 结果右键可将精确文件、扩展名或上级目录添加到任务排除规则，保存后强制重新分析。
- 分析快照绑定任务、连接、Bucket、路径、方向和规则指纹，默认 15 分钟过期；参数改变后旧计划不能入队。
- 每次执行持久关联同步任务与各传输批次，重新打开窗口仍可查看最近执行。
- 执行结果实时显示全部项目状态，可导出脱敏 JSON/CSV，并将可重试失败项重新入队。

## Unity / CLI 兼容性

- `s3explorer-cli version --output json` 增加 Contract API 和 Manifest Schema 的最小/最大兼容范围。
- Unity 插件不再以 S3 Explorer 产品补丁版本完全一致作为运行条件；只要 Contract API 和 Manifest Schema 范围兼容即可继续。
- `S3Explorer.Contracts.dll` 的 ABI `AssemblyVersion` 固定为 `1.0.0.0`，`FileVersion` 仍跟随产品版本。旧 Unity 插件需要一次性升级判断逻辑，此后普通补丁版本不再要求替换 DLL。

## CDN 匿名对象交付验证

- `publish --access preserve|anonymous-read|private` 提供显式的对象 ACL 策略，默认 `preserve` 不改动现有权限。
- `anonymous-read` 和 `private` 需要 `--yes`，范围只限当前发布 Manifest 中的对象与 `publish-manifest.json`。
- 工具不会修改 Bucket Policy 或 Public Access Block。Bucket Owner Enforced 或禁用 ACL 的存储会返回明确错误，由用户选择已有源站授权方案。
- `cdn cache-test` 对同一最终 URL 连续发送两次真实 HEAD 请求，分别输出 HTTP 状态、最终 URL 和 `X-Cache`/`CF-Cache-Status` 等缓存 Header，用于验证 MISS → HIT。如对象已在缓存，第一次也可能直接为 HIT。

## 安全与兼容边界

- 匿名读不是默认行为，也不在未确认时扩大到整个 Bucket。
- 同步报告中的凭据字段和预签名 URL 查询参数会脱敏。
- 删除传播仍默认关闭，入队前必须再次显式确认。
