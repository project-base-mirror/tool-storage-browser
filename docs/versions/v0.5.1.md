# S3 Explorer v0.5.1

- 日期：2026-07-27
- 状态：正式发布
- 主题：项目主页、GitHub Release 与客户端更新检查

## 已交付

### 项目与文档

- 新增响应式 GitHub Pages 项目主页，包含功能、CLI、兼容服务、路线图和稳定下载入口。
- 基于 S3 Browser 官方功能、Folder Sync 与 CLI 文档重新规划 v0.5–v0.8。
- 回填 v0.2.1–v0.5.0 的逐小版本记录，区分提交历史与真实 GitHub Release。

### 发布自动化

- 新增 tag 驱动的 GitHub Release workflow。
- 发布前验证 `vX.Y.Z` tag、`Directory.Build.props` 和版本记录完全一致。
- 在 Windows runner 执行全量测试和现有发布脚本。
- Release 上传 framework-dependent/self-contained ZIP、`release-metrics.json` 与 `SHA256SUMS.txt`。
- 工作流重新运行时覆盖同名资产，不重复创建 Release。

### 客户端

- 实现“工具 → 检查更新...”“帮助 → 打开项目主页”“帮助 → 报告问题”。
- 默认在启动后异步读取公开 GitHub Latest Release；设置页可关闭。
- 自动检查网络失败只写脱敏日志，不阻塞启动、不弹错误窗口。
- 发现新版时显示当前/最新版本、发布日期、版本说明和下载/Release 入口。
- 只接受稳定数字 tag 与 HTTPS 链接，不下载或执行任意更新程序。

## 隐私与安全

更新检查只发送普通 GitHub API GET 请求，不包含账户、Bucket、对象路径、日志、凭据或设备标识。客户端不静默安装，最终下载和安装由用户确认。

## 兼容性

- settings.json 新增 `CheckForUpdatesOnStartup`；旧配置缺少字段时默认启用。
- 发布资产名称成为主页与客户端依赖的稳定接口。
- 自动更新依赖仓库至少存在一个非 draft、非 prerelease 的 GitHub Release。

## 验证

- GitHub Release JSON 解析、稳定 tag、版本比较、推荐资产和 HTTPS 校验单元测试。
- GitHub Pages 桌面/390px 移动端复测，资源加载与控制台错误检查。
- 全量 153 项 .NET 测试、Release 零警告构建、CLI/UI smoke 与发布包结构检查。

## 已知限制

- v0.5.1 只负责检查和引导下载，不实现应用内静默升级或自替换。
- Draft 与 prerelease 不进入默认更新通道。
