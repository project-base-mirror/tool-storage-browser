# S3 Explorer v0.5.9

- 日期：2026-07-28
- 状态：正式发布
- 主题：连接导入预览与幂等合并

## 已交付

### 独立导入选择

- 导入预览使用“对象存储连接”和“CDN 配置”两个标签页，两类项目可以独立勾选。
- “本页全选 / 本页全不选”只改变当前标签页，不会暗中修改另一类选择。
- 对象存储已保存密钥与 CDN Token/Header 凭据分别显式确认，默认均不导入。
- 所选 CDN 关联缺少对象存储依赖时，窗口会显示数量并在确认前警告；未选择的连接不会被隐式导入。

### 语义匹配与重复导入

- 预览按非运行态配置内容区分新增、同名冲突和可复用项目，不再只比较名称。
- 内容等价的对象存储、CDN Profile、CDN 凭据和 Binding 复用本机记录与 ID，即使显示名称不同也不会新增副本。
- 覆盖内容不同的同名项时保留本机 ID，避免破坏现有引用；连续导入同一个连接包结果保持不变。
- CDN-only 导入可以复用本机内容等价的对象存储依赖；Storage-only 导入不会携带未选择的 CDN 配置。

## 安全与兼容性

- 连接包格式继续为 schema 3，不需要迁移现有文件。
- 显示名称、健康状态和最近连接时间不参与语义匹配。
- 只有显式选择对应凭据导入时，秘密值才在进程内参与等价比较；日志和磁盘不保存秘密值指纹。

## 验证

- Core 147 项、CDN Infrastructure 15 项、S3 Infrastructure 58 项、App 41 项，共 261 项测试通过。
- 覆盖同内容不同名称复用、重复导入幂等、CDN-only 依赖复用、Storage-only 隔离、凭据比较开关、双标签页选择和 12pt 最小窗口布局。
- Release 构建、发布包检查与隔离 UI Smoke 已完成；GitHub Release、版本化下载资产与 Pages 链接已完成线上复核。

## 已知限制

- 同名处理策略仍对本次导入全局生效，尚不能逐项指定重命名、覆盖或跳过。
- 缺少对象存储依赖的 CDN Binding 会跳过，不会在导入窗口内新建占位连接。
