# S3 Explorer v0.2.1

- 日期：2026-07-24

## 已交付

- 地址风格支持 Auto、Path Style 和 Virtual Hosted Style。
- 显示 Region 与签名 Region 分离，兼容要求固定签名区域的服务。
- 支持自定义 Host Header、临时重定向、Multi-Object Delete 与 Multipart Copy 开关。
- Endpoint 规范化保留协议、端口和基础路径，清理无效尾部斜杠。
- 忽略 TLS 证书错误必须由用户显式启用。
- 新增连接模型、JSON 配置和 S3 Client Factory 对应测试。

## 行为与兼容性

旧配置缺少新增字段时使用安全默认值，不要求迁移 profiles schema。高级参数面向 S3-compatible 服务，Amazon S3 仍可保持自动配置。
