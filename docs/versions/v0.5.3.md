# S3 Explorer v0.5.3

- 日期：2026-07-27
- 状态：正式发布
- 主题：连接迁移界面修复与版本化发布包

## 已交付

### 导入确认界面

- 修复“预览导入连接”窗口底部确认按钮在部分 Windows DPI/字体设置下被遮挡，导致无法确认导入的问题。
- 顶部说明、连接列表和底部操作区改用表格式自适应布局，不再依赖固定高度与绝对坐标。
- “全选”“全不选”“导入所选连接”使用适合中文文字的最小宽度和 34px 最小高度。
- “解锁连接包”窗口改为自适应布局，“解锁并预览”和“取消”按钮在大字体下仍完整可见。
- 保留 Enter 确认、Esc 取消、逐项勾选、凭据选择和同名连接处理行为。

### 发布与下载

- Windows ZIP 文件名加入版本号：`S3Explorer-v0.5.3-win-x64.zip`。
- Self-contained 包同步命名为 `S3Explorer-v0.5.3-win-x64-self-contained.zip`。
- 发布脚本从 `Directory.Build.props` 读取版本，Release 工作流、SHA-256 清单和指标文件使用同一版本化名称。
- 项目主页的下载、Release 和结构化数据链接更新到 v0.5.3。
- 客户端自动更新优先选择与 Release tag 完全一致的版本化 ZIP，同时保留对 v0.5.2 及更早无版本号资产的兼容。

## 兼容性

- `.s3connections` 文件格式、Profile Store 和同步任务格式均未变化。
- 不需要迁移本地数据；可直接覆盖升级。
- AWS 外部凭据来源不与本次界面热修复混合，顺延到 v0.5.4。

## 验证

- 新增导入预览和连接包解锁窗口的 12pt 大字体布局回归测试，检查按钮最小尺寸、首选尺寸和窗口内可见范围。
- 客户端更新测试验证版本化资产优先级与旧版无版本号资产回退。
- Core 114 项、Infrastructure 36 项、App 14 项，共 164 项测试通过。
- 隔离数据目录 UI 冒烟 15/15 通过。
- 本地发布检查验证两个版本化 ZIP 均包含桌面端与 CLI 可执行文件，并生成匹配的 SHA-256。
