# S3 Explorer v0.8.4

- 日期：2026-10-27
- 主题：安全预览编辑与传输可靠性
- 发布包和签名状态以 GitHub Release 资产为准。

## 新功能与改进

- 新增文本/JSON（2 MiB）、CSV 表格及静态 PNG/JPEG/BMP（8 MiB、1600 万像素）预览；不执行下载内容。文本可交给记事本编辑，确认后通过原 ETag 条件上传；冲突或失败保留本地修改。
- 大文件并行 Range 下载和服务端分片复制支持暂停恢复，统一限制数据请求并发；恢复时核对源身份、分段和目标状态，避免错误续传或移动误删。
- 普通上传、下载及文件夹批次统一覆盖、跳过、自动重命名和询问；修复 Windows 路径映射冲突、临时文件误覆盖及切换位置时上传目标漂移。
- 下载显示校验结果，支持 FULL_OBJECT SHA-256、SHA-1、CRC32；校验失败不替换目标，重试重新下载。
- 同步扫描有界并发并提前剪枝排除项，读取哈希时检测本地文件变化；降低队列检查点写入和列表刷新成本。
- 修复分片取消清理、落盘失败处理、下载尾部恢复和重试边界；“等待完成后退出”不再受 60 秒超时限制，可取消等待。

## 兼容性与限制

- 旧队列、设置和连续下载检查点仍可读取；新分段检查点不能由旧版安全解释，请勿带着进行中任务降级。
- MinIO 实测忽略条件删除，因此自动移动明确拒绝；普通复制、上传、下载不受此限制。其他服务商仍依赖各自的条件请求契约，不支持时不退回无条件覆盖/删除。
- 编辑仅开放受支持的 AWS/MinIO/R2 条件单次写入；KMS、客户密钥和 Object Lock/Legal Hold 对象只读。AWS/MinIO AES256 显式保留；未知 ACL/保护设置不能保证原样，确认框会提示。
- CRC32C、CRC64NVME、COMPOSITE 和无校验值不会标为应用已验证；未引入可能复用过期结果的持久哈希缓存。复制/移动不是跨对象原子事务。

## 验证

- 功能提交 `5a6b687` 的 Windows CI：741 项通过；隔离真实 MinIO：10 项通过、零跳过；编译和覆盖率门禁通过。
- 正式 tag 的发布流水线继续检查版本清单、锁定依赖、测试、覆盖率及安装包结构。未把自动化测试当作用户桌面 GUI 验收，也不声明实测了所有云服务。
