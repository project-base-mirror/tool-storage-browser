# S3 Explorer v0.4.0

- 日期：2026-07-25
- 状态：由 Git 历史回填；当时未创建 tag/Release
- 主题：对象剪贴板与批量复制移动

## 已交付

- 对象列表支持 Ctrl+C、Ctrl+X、Ctrl+V 的应用内对象剪贴板。
- 支持多对象/目录复制到或移动到指定 Bucket/Prefix。
- 复制移动先构建计划，处理源目标重叠、同路径、重复 Key 和目录展开。
- 操作进入持久传输队列，批量任务可暂停、取消和失败重试。
- 增加目标选择窗口和 MinIO 真实复制移动集成覆盖。

## 行为与兼容性

剪贴板保存 S3 对象身份而非把数据放入 Windows Clipboard。移动只有在复制成功后才删除源对象。

## 验证

- ObjectTransferPlanner 的路径、重叠和批次测试。
- MinIO 对象/目录复制移动集成测试。
- Release 构建与快捷键运行检查。

## 已知限制

此版本主要支持同一账户内操作；跨账户服务端 Copy 与下载上传回退仍在路线图中。
