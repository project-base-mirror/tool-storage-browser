## R2 条件复制

R2 使用其官方专用 `cf-copy-destination-if-none-match` / `cf-copy-destination-if-match` 条件，而不是误用普通 AWS 目标条件 Header。对不超过单次复制上限 5 GiB 的对象，支持要求目标不存在或匹配指定目标 ETag 的复制。

源 ETag 条件和目标条件是**两个独立时点**：选取来源内容时检查源条件，提交目标时检查目标条件。它们不是同时锁住两个对象的事务。来源在内容选取后再变化，不会触发删除；本流程始终保留来源。不支持的分片、恢复断点或错误不会退回无条件覆盖。

官方协议与测试清单见 [Provider 补充证据](Provider-Copy-Followups-2026-11-04.md)。当前没有真实 R2 账号验证，记录客户端与签名检查不能代替服务端实测。

## Metadata 另存的正确性

读取、展示、保存时保留 SDK 返回的 Metadata 和 Header 字符串，不再擅自去除值两侧的空白。上传流程原有的输入规范化保持独立。这里不承诺原始 HTTP 字节保真，也不声称任意 Unicode Metadata 已实现线上编码往返。

保存会先提交正在编辑的表格单元格，避免最后一次输入丢失。建议的新 Key 按 UTF-8 字节限制生成。冲突、超时、取消或服务端错误会给出可操作说明并保留诊断信息；响应丢失后不能把最终错误当成“目标一定不存在”，应先刷新核对，不自动覆盖、删除或更换目标重试。

Tags 由服务端在执行复制时从指定版本读取，它们仍可单独变化。旧版本保留和双重 ETag 条件都不是完整属性版本的原子比较交换。详见 [Metadata 快照说明](Metadata-Snapshot-Copy-2026-11-04.md)。

## 特殊 Key 链接与重定向

前导斜杠本身不是 S3 协议禁止项。问题来自锁定 AWS SDK 的 URL 构造分界；修复在**签名前**保留精确路径，再交给 SDK 的公开 SigV4 签名器，不在签名后修改 URL。

预签名下载采用明确的 GET/HEAD 支持范围；上传、特殊加密、访问点和目录 Bucket 等高级模式不会被静默忽略。浏览器会规范化的字面 `.` / `..` 路径段不能仅凭内部请求 URI 保真就宣称链接可用，应使用应用内下载。

实现范围和锁定 SDK 源码见 [精确 Key 链接说明](Exact-Key-Links-and-Redirects.md)。

自动跳转在重新签名之前核对协议、端口、精确 Bucket/Key/查询参数及目标服务身份。不能仅凭主机名“看起来像 S3”就转发签名和会话令牌。跨主机仅支持可确认的同分区 AWS 区域端点；自定义服务不会因 Location Header 而把凭据转发到另一个主机。若 .NET 解析跳转 Location 时已折叠字面点路径段，应用无法恢复原始身份，仍拒绝重发；请直接配置正确区域 Endpoint，原始应用内请求继续保留该 Key。

## 仍不能由客户端变成原子操作的情况

### Metadata 原地编辑

AWS 的 ETag 不包含 Metadata。即使对象内容完全相同，Metadata、Tags、ACL 或当前版本仍可能变化。CopyObject 的目标 ETag 条件、预先 HEAD、保留历史版本，都不能原子地证明完整属性没有被其他客户端修改。因此继续提供明确的另存工作流，不把它包装成已恢复安全原地编辑。

### 自动移动 / 重命名

普通 S3 移动是复制再删除，不是原子重命名。现有 AWS 移动按内容 ETag 条件删除来源，但不锁定复制后的目标，也不能通过 ETag 检测仅属性发生的变化。移动窗口说明这一边界，避免承诺不存在的两对象事务。

Supabase S3 的条件删除与目标条件、UploadPartCopy 条件没有所需保证，不能用“先 HEAD”或客户端中转绕过。其原生 REST move 是另一种服务接口，需要单独的 REST 身份和明确的 Endpoint 绑定，文档规定 5 GB 上限并会改变 owner；现有 S3 密钥不能被静默当作 REST 凭据。若使用外部原生流程，需先确认身份、所有权及权限变化。中转 GET/PUT 也不能自动保证所有 Metadata/Header 往返，所以没有把它冒充为无损大对象移动。

### MinIO 与未知兼容服务

官方 MinIO 会规范化某些前导斜杠 Key，可能访问或删除另一个对象。客户端不能靠正确签名修复服务端这种行为。继续拒绝已知危险 Key，并保留正常目录 marker、一般空白、反斜杠等已区分的情况。Custom/未知服务没有可信的能力证明；不根据 Server Header 猜测安全性。应正确选择实际服务类型。
