# 2026-11-04 审计修复

基线：v0.8.7 / `dbf63417eaef0a4f5079259a5a1461c5b459870e`。本记录属于修复分支，不代表已合并或发布。没有改版本号、创建 tag 或发布资产。

## 逐项处理

| # | 原审计项目 | 处理与边界 |
|---|---|---|
| 1 | 同步路径重复转义 | 同步直接解析扫描得到的真实相对文件名，验证目录边界和重解析点，不再二次编码下划线。无法保真的 Windows 文件名明确拒绝。 |
| 2 | 重命名覆盖／复制移动冲突 | 重命名预检后仍使用原子非覆盖条件；队列执行传递冲突策略。AWS CopyObject 使用目标条件，MinIO 通过条件完成分片。未验证服务商和 MinIO 空对象安全拒绝；排队后冲突不静默覆盖。 |
| 3 | GUI/CLI 旧配置快照覆盖 | 在存储锁内基于原始、编辑、最新三个状态按记录 ID 合并；其他进程的独立更改保留，同记录冲突明确拒绝。 |
| 4 | S3 路径百分号往返 | 对 profile/bucket/key 各段对称编码与解码，保留真实 `%20`、空格、问号、井号和斜杠语义。 |
| 5 | Windows CLI 大小写覆盖 | 排序后先预留整批目标名称，映射冲突自动改名；最终文件提交禁止覆盖后来出现的目标。 |
| 6 | Metadata 旧版本／加密属性丢失 | **保守止血，未完整恢复编辑功能。** 后端在网络访问前拒绝原地重写，GUI 只读。因现有接口缺完整属性和当前对象条件，不能安全保证旧版本、KMS/BucketKey、非编辑 Header、ACL/保留状态。可用服务商原生工具操作。 |
| 7 | 忽略证书时 gzip 下载空文件 | 兼容 HTTP transport 禁止自动解压，HEAD 长度和 GET 原始字节一致；加入实际 loopback SocketsHttpHandler 回归。 |
| 8 | GUI 上传跟随链接 | 目录遍历跳过目录/文件符号链接和 junction，避免递归环及所选目录外内容进入队列。 |
| 9 | 多条无凭据连接无法补齐 | 配置结构验证与网络操作凭据验证分离，占位连接可分次编辑并整理分组。 |
| 10 | 类型往返丢认证／高级设置 | 按 provider 保存认证来源、凭据引用、AWS 参数；恢复 signature region、隐藏非默认 region 和未列出的 storage class。不兼容凭据保持未选择。 |
| 11 | HTTPS 丢端口／导入后旧密钥 | HTTPS 往返保留显式端口；导入合并后重新解析全部共享凭据引用并采用保存返回的最新状态。 |
| 12 | 401/403 连接假成功 | 认证错误不能归类为受限列表；AccessDenied 只有已配置桶成功进行认证读取才视为已验证，否则显示失败/未验证。 |
| 13 | 自动连接／损坏密文备份恢复 | 记录最后连接 ID 并按开关恢复，缺失/无凭据条目安全跳过；备份候选完整解密、解析和语义校验后才接受。 |
| 14 | GUI 分片阈值超限 | GUI/设置上限统一到 5120 MiB，服务层独立限制单 PUT，不能由直接调用或旧设置绕过。 |
| 15 | CLI 中断上传残留 | CLI 明确为非持久执行；失败/取消时中止其 multipart，清理自身下载临时文件，GUI 持久队列保留可恢复状态。强制杀进程、断电或服务端拒绝 Abort 仍无法保证清理，错误保留 UploadId 供核对。 |
| 16 | 删除目录遗漏 marker | 使用无 delimiter 的原始分页列表，包含根及所有嵌套目录 marker；不再用浏览器目录投影代替删除对象清单。 |
| 17 | MinIO 公共 ACL／管理权限耦合 | 公共 ACL 在 GUI/后端拒绝并指向 Bucket Policy；概览各特性独立读取，失败记为未知而非默认配置，其他页仍可读取。未知安全设置禁止直接保存。 |
| 18 | Supabase 条件能力误判 | **安全能力收紧。** 未验证条件删除禁止自动移动；Supabase 分片复制拒绝，不能凭接受 Header 或返回 VersionId 推断条件/固定版本生效。 |
| 19 | MSI 回滚／自定义目录 | MajorUpgrade 放进安装事务；注册表恢复安装目录，updater 显式传入当前目录；完成状态在启动检查之后记录。真实 Windows MSI 失败回滚仍需安装器生命周期测试。 |
| 20 | 便携识别／清单提前发布 | 通过构建程序集元数据识别自包含包，安装注册需匹配当前路径；Pages 验证公开 Release 资产/digest 后才能部署，Release 成功后重触发 Pages。未执行真实发布。 |

另修复清空 Bucket 绕过单对象删除策略和批删降级的问题；逐对象错误不能计为成功。

## 验证方式

- 云端已运行 `git diff --check`、XML/YAML 解析和 `python scripts/test_update_safety.py`（4 项静态结构门禁）。这些只验证结构，不等同 .NET 编译或 Windows 安装实测。
- 新增/扩展 xUnit 回归覆盖路径、配置三方合并、无凭据恢复、认证草稿、端口、损坏密文、共享凭据、传输条件、gzip 原始字节、分片失败清理、ACL 能力、便携类型和 updater 启动失败。
- 当前云电脑无 .NET/PowerShell，未安装新软件。编译、xUnit、现有 Windows 和隔离 MinIO 集成结果以草稿 PR 的 **当前提交** Validate 检查为准；未完成/失败不得写成通过。
- 不访问用户电脑、真实用户配置、真实凭据、真实 R2/AWS/Supabase 资源。没有实际 Windows junction、真实 MSI 升级失败/回滚、真实 R2 或托管 Supabase 验证。

## 保留限制

- Metadata 写入仍未安全实现，暂只读，不把移除不安全写入等同完整功能修复。
- 未验证服务商的自动移动/条件复制保持拒绝；不会降级成无条件覆盖或无条件删源。
- CLI 非持久清理不能跨强制终止恢复；需要可靠跨进程恢复时使用 GUI 持久传输队列。
- URI 序列化保持精确 Key，但旧有 GUI 导航/普通前缀列表仍会规范化重复斜杠和反斜杠；本轮往返测试不代表这些特殊前缀导航已完整修复。
- 本轮不修复尚未列入本次二十项的 HTTP 重定向重新签名及非 ASCII Header 编码候选；它们需要独立协议设计与回归。
