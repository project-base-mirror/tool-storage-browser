# 连接导入导出

S3 Explorer 0.5.2 起使用 `.s3connections` 连接包在不同 Windows 设备或用户之间迁移连接。格式 3 起，连接包还可携带相关 CDN Profile、Bucket/前缀关联和显式选择的 CDN 凭据。连接包不包含传输队列、同步任务、应用设置、运行状态或对象数据。

## 导出

在“文件”菜单中可选择“导出当前连接”或“导出全部连接”，账户树右键菜单也可导出单个连接。导出当前连接时，只包含与该对象存储连接相关的 CDN Profile、Binding 和凭据；导出全部连接时，也包含尚未建立 Binding 的独立 CDN Profile 与凭据。

默认不勾选“包含凭据”时，连接包省略以下全部字段：

- Access Key
- Secret Key
- Session Token
- CDN Bearer Token 或自定义 Header Secret

无凭据包仍保留 CDN 基础 URL、预热/刷新参数和 Bucket/前缀关联，但会移除 CDN `CredentialId`，避免在目标设备形成指向不存在凭据的引用。

这种连接包适合提交到内部配置仓库、发给同事作为 Endpoint 模板，或在不可信传输渠道中移动。已保存密钥来源在导入后必须补充凭据；AWS 外部来源会保留来源类型和非敏感 Profile 名称，只要目标环境具备对应 Profile、环境变量或角色即可直接解析。

勾选“包含凭据”时，必须设置至少 8 个字符的迁移密码。S3 已保存密钥、CDN Token/Header Secret、普通配置和关联会作为一个整体加密，目标设备输入同一密码后才能预览。建议通过与连接包不同的安全渠道传递密码；迁移完成后删除不再需要的含凭据连接包。

## 导入与预览

选择连接包后，受密码保护的文件先要求解锁，然后显示导入预览：

1. “对象存储连接”和“CDN 配置”使用两个标签页，默认分别勾选包内全部项目；“本页全选/本页全不选”只作用于当前标签页。
2. 两类项目可以独立选择。只选对象存储不会隐式导入 CDN；只选 CDN 时会复用本机内容等价的对象存储依赖。
3. 若所选 CDN Binding 既没有选中对应对象存储，也找不到本机等价连接，预览会显示依赖缺失，确认前再次提示；配置仍可导入，但该 Binding 会跳过。
4. “导入对象存储凭据”和“导入 CDN Token/Header 凭据”是两个独立选项，默认均关闭。
5. 预览会按实际配置内容标出“新增”“同名但配置不同”或“复用本机项目”，而不只比较显示名称。
6. 确认后才在一个事务中写入当前用户的 S3/CDN 配置；取消或保存失败不会留下半套配置。

完全等价的对象存储连接、CDN Profile、CDN 凭据和 Bucket/前缀 Binding 会直接复用本机记录及 ID，即使显示名称不同也不会再创建副本。健康状态、最近检查/成功时间和显示名称不参与等价判断。连续导入同一个包是幂等操作；只有选择导入相应凭据时，秘密值才会在内存中参与等价比较。

同名连接可选择三种全局策略：

| 策略 | 行为 |
| --- | --- |
| 自动重命名 | 对内容不同的同名项保留本地记录，并将导入的 S3 连接、CDN Profile 或 CDN 凭据改为“名称 (导入)”或带数字后缀 |
| 覆盖同名连接 | 用导入配置替换同名项，同时保留本地 S3/CDN/凭据/Binding ID，避免破坏现有引用 |
| 跳过同名连接 | 本次不处理同名项及无法安全重建的关联 |

## 凭据保护

- 日常连接配置继续使用 Windows DPAPI CurrentUser 保护 Secret Key 和 Session Token，只能由同一 Windows 用户解密。
- 含凭据的连接包不复制 S3 或 CDN 的 DPAPI 密文，而是使用迁移密码重新保护明文载荷，以便跨设备导入；导入后再分别写入各自的 DPAPI 存储。
- 连接包使用 PBKDF2-SHA256（210,000 次迭代）派生 256 位密钥，并使用 AES-256-GCM 认证加密整个配置载荷。密文被修改、密码错误或认证标签不匹配时会拒绝导入。
- 无凭据连接包是可读 JSON；含凭据连接包的外层只公开格式版本、导出时间、连接数量和加密参数。
- 应用日志只记录对象存储/CDN 的选择数量、变更数量、策略、两类凭据是否选择和文件路径，不记录密码、Access Key、Secret Key、Session Token、CDN Token、Header Secret 或秘密值指纹。
- AWS shared profile 只导出 Profile 名称；环境变量、容器角色和实例角色只导出来源枚举，不导出解析后的 Access Key、Secret Key、Session Token 或 SDK 缓存。

迁移密码不保存到应用中，也没有找回或重置机制。忘记密码时只能重新导出连接包。

实现使用 .NET 提供的 [AesGcm](https://learn.microsoft.com/dotnet/api/system.security.cryptography.aesgcm) 和一次性 [Rfc2898DeriveBytes.Pbkdf2](https://learn.microsoft.com/dotnet/api/system.security.cryptography.rfc2898derivebytes.pbkdf2) API。

## 格式与限制

- 当前格式标识为 `s3explorer-connections`，格式版本为 `3`；导入器仍兼容格式版本 `1` 和 `2`。旧版客户端不能读取格式 3。
- 单个连接包最多包含 1,000 个连接，文件最大 16 MiB。
- 导入器严格拒绝未知格式版本和不支持的加密参数，不会猜测或降级解密。
- 健康状态、最近成功时间等本机运行数据不导出；导入后的连接从“未检查”开始。
- AWS shared profile、环境变量、容器角色、实例角色和默认链已进入连接包格式，但只携带非敏感来源引用。
- CDN 普通配置与独立凭据在载荷中保持逻辑分离；无凭据包不包含 CDN Secret，含凭据包则加密整个载荷。
- AWS SSO、AssumeRole 与 Web Identity 尚未进入连接包；它们涉及独立令牌缓存和会话生命周期，将在高级身份阶段接入。
